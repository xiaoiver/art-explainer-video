# 沉静赏析

原画局部承担证据的默认制作主线。更快、更风趣的贴纸与音效用趣味艺术史，画中人物对白用名画小剧场；多作品解读和系列片头可以与本风格组合，分别见 [多作品解读](../../shared/multi-artwork.md) 与 [统一片头](../../shared/series-intro.md)。

生成与渲染的接入见 [工具接入](../../shared/tooling.md) 和 [独立 Remotion 渲染](../../shared/remotion-rendering.md)，只在执行对应工具时读取。

## 制作主线

### 1. 资料与原画

优先查馆藏作品页和高清原图，再看馆方短文；《读画》和陈丹青《局部》只借节奏，不当证据。记录 URL、访问日期及图像使用说明。区分“馆方事实”“画面可见内容”“本片解读”。高清图公开可看并不自动等于可以任意转载。来源分层见 [画面与脚本](../../shared/art-direction.md)。

确定画心边界，排除装裱、空白与边框。每个讲解点都要能在实际原图上定位；落款、人物和细线无法辨认时删改讲解，不用生成画面补出所谓原作证据。

构图分析、笔法、颜料和肌理使用原画。馆藏或档案高清图上看得见时，可以像讲水墨皴擦一样，选一两处油画笔触或其他媒介的表面细节；看不见就改写旁白。不要求每支西方绘画都分析笔触。生成画面承担氛围与想象性延展，标注其性质，不用来证明技法。研究、构图、表面细节和提示词见 [画面与脚本](../../shared/art-direction.md)。

古画研究也检查题款、题跋与印章。有可靠来源、能够帮助理解画名、画意或流传经历时，把其中一两处写成故事；不要求每片都讲，也不逐印报名字。分清原作者题款、后人题跋及鉴藏印，保留各自年代。本用户2026-11-05希望这类局部讲解同时保留全图视角：默认使用全图小地图（minimap），以定位框和连线指明当前局部在全图中的位置，放大细读期间持续可见；其他用户按其偏好选择。具体取舍、释读与镜头方法见 [题跋与印章](../../shared/inscriptions-and-seals.md)。这套流程只用于中国书画，不套到西方绘画或其他非中国书画作品上。

### 2. 脚本与分镜

先问一个能在画上核对的问题，再讲看见了什么，馆方事实只用一两句；个人感受放在最后，并与史实分开。带观众在全景和局部间移动。单画模式默认只讲一件主作品；当前画面单独看不清时，可短暂对照另一件有依据的原图。用户明确选择多作品时，改按共同问题组织交替与比较，不把“只能短暂对照”套到多画模式，见 [多作品解读](../../shared/multi-artwork.md)。节奏与对照见 [画面与脚本](../../shared/art-direction.md)。

手机观众很少有机会站到原作前面。高清局部铺满屏幕时，立轴和大幅绢本都会失去高低，看起来像壁纸。单画细读默认在首段持续局部讲解前建立可见尺幅，尤其是作品大小影响观看的立轴、长卷或大画。多作品或趣味艺术史先看共同问题：重点是造型、表情或人物关系、尺幅不参与解释时，可省略身高和尺寸对比；用户明确不需要时直接省略。选用尺幅时，旁白报厘米不能替代可见参照。做法、什么算有效一拍，见 [画面与脚本](../../shared/art-direction.md)。

长卷开头优先让原画占据主要画面，以满宽、较高的视窗缓慢浏览，文字退到辅助位置。可以先浏览一段，再紧接可见尺幅，之后进入局部细读；不为在短开场滚完整卷而加速。方向、取段、高清拼接、转场与可复用组件见 [长卷开头](../../shared/long-scroll-opening.md)。

使用人物尺幅示意时，可选随附的自然站姿透明素材；以头顶到鞋底的可见高度校准，整体等比缩放。素材、布局脚本与合成方法见 [尺幅参照人物](../../shared/scale-reference.md)。

多段赏析可使用顶部章节导航，尤其适合竖版：固定显示短章名，以细线和文字高亮标出当前段落。本用户2026-11-05在《容膝斋图》制作中要求继续保留顶部进度条与章节，横版章节列表与作品名同一行并靠右，不另起一行；后续该用户系列默认沿用，加入题印小地图时也不移除。该集不使用「名画开小差」字标；旧案例的系列名、片头或标识不自动加入新片，是否复用由当前任务决定。其他用户按其偏好选择。章节随脚本重新组织，时码随实际音频和剪辑更新。可复用组件与《万壑松风图》配置见 [顶部章节导航](../../shared/chapter-navigation.md)。

脚本写清旁白、原画位置、镜头意图、声音提示和素材性质。尺幅镜头要写明对照方法、馆方尺寸原文、来源 URL 与访问日期，以及它相对于第一段持续局部讲解的位置。配音前是预估时长；获得实际音频后再对齐镜头与停顿。不要为了凑时长反复插入没有讲解作用的动态。

### 3. 试样与生成

开头尽量围绕具体旁白合理使用一小段 AI 动效增加吸引力，按[开头的 AI 动效](../../shared/art-direction.md#开头的-ai-动效)设计、标注并验收；不适合或用户要求静态原画时可省略。先选一个能代表本片的镜头，测试原画质感、动态幅度和音色。古画水墨路线优先保持纸绢、墨色和笔触，避免自动转成写实山景；其他画种按原作媒介决定风格。

声音样本用年龄感、音域、语速、气息等特征描述。用户确认后，保存该合成音色参考及生成参数用于后续段落，避免模仿具体在世人物。

按已选方案生成有限数量的素材。异步任务超时先找回原任务，不重复下单。每条素材记录来源、生成工具、模型、参考素材、实际时长和选用状态。

### 4. 声音、编排与精剪

人声、BGM、环境音效保持分轨。配乐在讲解时让位，音效服务画面中的具体事件；保留看画的呼吸空间。音色延续、音乐循环、响度与字幕时码见 [声音制作](../../shared/audio.md)。需要新环境音或具体动作拟音时，再读[音效选材与来源台账](../../shared/sound-sourcing.md)，记录声音时码、源片段、许可与试听状态；真实录音和生成音按用途选择，复用保留原始性质。

剪映原生应用可用时，默认用它完成节奏、声音与字幕精剪；用户另选工具时按其要求执行。先输出无烧录字幕的画面底片和独立声音轨，再建立可编辑字幕轨，并在原生界面验收、导出。特效以帮助观看为准，字号、淡入和层级以真实预览为准。

字幕、标题与资料标注分配固定角色，保留已获认可的底部字幕样式。本用户2026-11-04在《渔村小雪图》中选定南西油墨宋：后续古画封面主标题与视频篇名优先用它的真实字体文件；连续解说用宋体，少量重点词保持同字族的淡金强调；文楷按需用于景名、诗句和短释文。没有相应文字层时不必用齐三款，层级主要靠字号、字重、留白和位置建立。旧案例的多字体探索不作为新项目默认清单，其他用户或明确指定的风格另行选择。「名画开小差」已确认的思源宋体字标保持原版，见 [系列片头](../../shared/series-intro.md)。准确字体的封面采用参考生成的无字底图加真实排字，继续保持画字融合。字体来源、实际加载、剪映回退与验收见 [字体与文字层级](../../shared/typography.md)。

原生工程兼容性、导出和验收见 [剪辑与交付](../../shared/editing-delivery.md)。

### 5. 验收与发布素材

逐镜检查关键讲解点、画心边界、AI 标记、字幕内容和转场。选择展示尺幅时检查：第一段持续局部讲解之前，至少一拍采用同比例示意、全幅相对身高或有实物参照的真实展厅影像；馆方厘米数已短暂上屏，且参照没有被裁掉。长卷先浏览时检查开始、中间、结束及接尺幅的叠化，不把浏览局部称为完整全卷。只有旁白或只有画中小人，不算尺幅这一拍。对最终文件检查实际尺寸、帧率、时长、完整解码和响度；记录哪些内容已人工听看，哪些仅通过数据验证。自动转录、波形和元数据不能证明听感合格。

按用户选择的比例另做封面，实际读取像素核对。本系列古画封面优先传统宋体或相近书卷气字形，让文字融入纸绢留白，与画面共同构图；需要重构时使用参考图生图。随图生成文字与独立排字按融合效果、准确性和可编辑需求选择，方法与实例见 [封面的画字融合](../../shared/cover-design.md)。这是已确认的系列偏好，新项目尊重用户和原作媒介。

标题文案围绕画中问题和观看收获；需要工具介绍时写各自承担的具体环节，用户要求只写赏析时不加入工具介绍。资料署名和生成范围仍保留在交付记录及必要的片内标记中。

默认交付本地文件或用户选定的素材平台。**导出与制作授权不包含社交平台上传、分享或发布。** 剪映导出后读取最新界面，不在完成页盲按回车；先验证本地文件，再直接关闭分享页。

## 计划与案例

沿用既有工程结构。新工程可使用 [计划文件](../../shared/project-format.md) 记录尺寸、素材和镜头，`editing_style` 写 `contemplative`。运行：

```bash
python3 scripts/validate_plan.py /path/to/project.json
python3 scripts/validate_plan.py /path/to/project.json --check-files --probe
```

第一条检查计划，第二条额外检查本地素材与已配置的交付媒体。脚本不会生成、渲染、上传文件，也不能替代画作研究、试听或逐镜验收。

制作记录至少保留：资料来源、尺幅所据馆方厘米与 URL、批准的创作选择、素材清单及性质、时间线、工具版本、音色参考、混音参数、字幕文件、原生工程状态、实际导出指标和未验证项。字段表见 [剪辑与交付](../../shared/editing-delivery.md)。中途恢复时先读记录，再读取有关素材；不要把开工前明文备份称作最终编辑工程。
