# 字体与文字层级

按本集实际出现的文字角色选用下表。用户另有指定时，沿用其选择。

## 当前默认

| 文字角色 | 字体选择 | 排版与使用 |
| --- | --- | --- |
| 古画封面主标题、开篇作品名与篇名栏 | 字制区喜脉喜欢体 | 用真实字体文件排字；优先用于大字，避让画中主体，并检查缩略图中细笔画的可读性。无需在每个镜头重复大标题 |
| 顶部章节导航 | 霞鹜文楷 | 横版与左侧作品名同一行、靠右；当前章节高亮，保留细进度线。详见章节导航指南 |
| 底部连续解说 | Songti SC 宋体 | 按意群分行；每条字幕末尾去掉句号、逗号、问号、感叹号等标点，保留句中必要标点和书名号等成对符号；无整块底板、轻阴影，少量重点词用淡金强调 |
| 四字景名、诗句、短释文与必要的关键词卡 | 霞鹜文楷；按需要选Regular或Medium | 保留自然字形，以字号、字重、字距与留白建立层级；不是每镜都要加景名或关键词卡 |
| 片内作者名、年代、来源等资料小字 | Songti SC 宋体 | 小字先保证可读，不为每类资料另加黑体或英文衬线 |

字幕内的重点词继续使用宋体，只改变强调色，不切换到文楷。沿用《早春图》已有的少量淡金强调思路，按语义选择少数词，避免整句变黄、逐字变色或高亮跳动；颜色明度需结合底图在手机尺寸检查。独立关键词卡与字幕内高亮是不同文字层。

「名画开小差」的固定字标随[系列片头](series-intro.md)复用。

展示字、手写吐槽字和英文斜体不再自动成套加入。确有海报、漫画或其他明确风格需要时再选，先看它是否承担了现有排版无法完成的任务。通过文字大小、字重、颜色、竖横排、位置和入场节奏区分角色；字幕保持稳定，必要的标题和重点词才出现，不给每镜添加泛泛的观看指令或副标题。

原画题款、署名与印章保留真实图像。现代释文可用文楷排录，与原迹分开呈现，不能用字体或AI重写来冒充古人手迹；证据方法见[题跋与印章](inscriptions-and-seals.md)。

## 字体来源与落地

字制区喜脉喜欢体由用户提供的 `字制区喜脉喜欢体1.00_猫啃网.zip` 取得；此前提供的包位于 `~/Downloads/字制区喜脉喜欢体1.00_猫啃网.zip`，需要时先确认仍存在并从中读取真实 TTF，字体 family 含 `FontQu Smile`，PostScript 名为 `xihuanti`。包内说明称个人和企业可免费商用，但需按实际用途核对来源、许可和再分发条件，不把字体打包进公开仓库。若文件缺失，说明实际回退，勿声称已加载。

霞鹜文楷兼有楷体与仿宋的气质，官方说明更适合诗词等中等长度文本或注释；本用户另指定将它用于顶部章节导航，也可按需用于景名、诗句和短说明，不替换连续字幕。按用户链接使用原项目，避免将霞鹜漫黑或其他文楷衍生版视为同一文件。来源：[官方README](https://github.com/lxgw/LxgwWenkai#readme)、[字体目录](https://github.com/lxgw/LxgwWenkai/tree/main/fonts/TTF)、[OFL许可](https://github.com/lxgw/LxgwWenkai/blob/main/OFL.txt)。字体选择与实际安装、渲染分别记录，不把规则已更新等同于字体已生效。

制作时记录实际字体文件或可恢复来源、版本、字重、字号、行距、字距、颜色与备用字体；随项目分发开源字体时保留相应版权和许可文件，系统字体的再分发条件另行核对。无需为选字体额外购买或全局修改系统设置。

用本集真实文字检查人名、繁体题跋、生僻字、数字和标点。字体不存在或缺字时选择有依据的替代并记录，不把回退渲染称作文楷已生效。从在线字体服务取得的文字子集只覆盖请求字符；改文案后重新检查覆盖范围，不能将子集当作完整字库。

《画里的猫》出现过字幕“华喦”显示方框：所用 Songti TTC 的实际 face 缺少“喦”，配置中有文字不等于成片能显示。修复时仅为受影响字幕选支持该字的相近宋体，保持其余字幕样式，关闭草稿后改配置或在原生界面修改；重新打开剪映并在实际时码预览，导出后取帧检查完整字形。该次本机简宋有效，但路径、字库和 TTC face 随系统而变，不能硬编码为通用保证。保留可恢复的字体选择与替代方法，系统字体是否可随包分发需另行核对。

Remotion完成字体注册与加载后再截图、渲染，避免先出回退字体。剪映按实际字体名称及预览检查，不同画幅或软件的字号不能直接互抄。保留字形比例，不为凑行宽拉伸、压斜或假造字重；先缩短标题、调整换行与字号。

字体注册后，在实际剪映工程里核对字形和字重。`.ttc` 含多个字重时记录所选 face，无法确认时保留原生预览。旧片中的回退现象与处理见[《渔村小雪图》剪映验收](../cases/contemplative/wangshen-yucunxiaoxue-produced-case.md#剪映与验收)。

## 封面、可编辑性与验收

准确字体的封面采用[无字底图加真实排字](cover-design.md#选择制作方式)。保留无字底图、透明标题层和排字源；要修改字符，需使用字体文件与排字源。

剪映独立字幕轨可直接修改；烘焙在底片里的标题、导航或资料文字需改合成源并重新渲染。记录实际可编辑范围，不把所有文字都称作剪映字幕。

在完整分辨率和手机缩略尺寸检查：字幕耐读，短标题有层级，资料清楚；作品名、人名与释文无缺字、截字、意外回退或笔画被裁切。实际运动落稳后再看排版，不只看字体样板。原生界面验证与配置记录分开，见[剪辑与交付](editing-delivery.md)。

采用[趣味艺术史](../styles/playful/STYLE.md)时，贴纸、纸片和气泡仍可用同套字体设计；活泼来自内容、构图与动作，不默认重启多字族轮换。原文题款、现代排录和编辑吐槽分层，虚构对白不伪装成艺术家真实引语。
