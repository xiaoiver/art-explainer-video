# 尺幅参照人物

需要人物尺幅示意时，可复用 [透明人物 PNG](../assets/scale-reference/viewer-standing-left.png) 和 [测量元数据](../assets/scale-reference/viewer-standing-left.json)。人物是《万壑松风图》制作中确认的原创合成插画：略微侧背身、朝左看画、双手轻放身后，灰褐色简化衣褶。把它放在原画右侧；横版、竖版都可重新排版。它是尺寸示意图形，不是展厅真人或画中人物。

这是一种已选造型，不强制每片使用。其他风格也应保留自然成人比例、肩颈与鞋底，避免圆头标识人、过长躯干或单独拉长腿部。人物过宽时重排留白或缩小画与人的整体组合，不单独压窄人物。

## 精确缩放

以人物**头顶到鞋底的可见范围**计身高，不能把透明 PNG 画布高度当成人身高。元数据保留图像尺寸、可见边界与 SHA256。边界按 alpha≥16 的主体范围测量并经画面检查；可见框以外的极低 alpha 噪点由 SVG 视窗裁去。素材变动后重新检查边界，不能沿用旧值。

设原画显示高度为 H 像素、馆方实物高度为 C 厘米、参照身高为 P 厘米，则人物高度为 `H × P / C`。宽度使用同一个缩放因子；头顶定位为 `共同底线 − 人物高度`。图形默认没有固定厘米，170 cm 是每次布置时明确采用的参照假定，可以修改。

标准库脚本可输出布局和自包含 SVG（SVG 内嵌该 PNG，不重画人物）：

```bash
python3 scripts/scale_reference.py \
  --painting-height-cm 188.7 --painting-height-px 1000 \
  --person-height-cm 170 --baseline-px 1470 --left-px 835 \
  --output-svg /path/to/project/library/scale-viewer.svg
```

本例输出人物高约 900.901 px、宽约 214.830 px、顶部约 569.099 px。只用于说明算法；新画作必须重新核对馆方尺寸，并按新画幅选择画作显示高度、底线与左右位置。编辑器按输出宽高等比放置 SVG，保持其 `viewBox`，不要再次用“填满”把它拉伸。

## 合成与验收

原画、人物、尺线和文字分别保留图层。生成人物预览时即使要求“不改原画”，也可能重绘画作或改变尺寸；这种整张预览只用于选造型，正式镜头用馆方原图加独立人物素材合成。生成图上写着“170 cm”不意味着比例已经正确。

画面注明“按馆方尺寸示意”和实际采用的参照身高；画心、本幅与装裱范围跟随馆方档案。不要从共同底线推导真实悬挂高度。检查整个人物没有被裁掉、头脚对应计算值、双轴缩放相同、人物与原画不重叠、字幕不遮挡尺寸。检查开始、中间和结束帧，确认入场动效没有造成最终定位偏差。

素材生成方式为内置图像编辑工具，以用户确认的合成人物为参考分离透明背景；没有真人照片或真人身份参考。原始预览中的博物馆画作、文字和界面均不包含在随附 PNG 中。
