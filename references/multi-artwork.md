# 多作品解读：围绕一个问题组织一组画

用户明确选择同一艺术家的多件作品、不同艺术家的比较，或围绕主题策划一集时使用。单幅赏析仍可只短暂引用另一件作品；不要因为支持本模式就自动扩充选题。剪辑风格另选：多作品可以沉静，也可以用[趣味艺术史剪辑](playful-editing.md)。

## 三种叙事入口

| 入口 | 要回答的问题 | 研究与取舍 |
| --- | --- | --- |
| 同一艺术家的系列或阶段 | 同一个人，为什么反复画同一主题？哪些画法变了？ | 区分创作、修改与展出年代；系列不一定有先后升级关系；晚期变化不能直接归因于疾病或心理状态 |
| 不同艺术家的同题比较 | 同样画山、水、宴席或肖像，为何观看体验不同？ | 先找到能在双方原图上核对的共同问题；不把画种、年代、功能不同硬凑成高下比赛 |
| 作品之间的关联叙事 | 某个构图、题材或观看方式怎样被回应和改写？ | 视觉相似可作比较；师承、影响、委托、致敬或争论需独立来源，不从“长得像”推出历史关系 |

先选问题，再选画。短片可从两至三件主作品试起，但数量随片长、信息量和已有授权决定，不设固定张数；多到每件只能闪过时缩小问题或拆集。每件入选作品应回答一个比较点，删掉没有贡献的名画。

用共同问题组织段落，例如“从哪进入 → 怎样往深处走 → 两种观看感受”，而不是“甲的完整介绍 → 乙的完整介绍 → 丙的完整介绍”。允许一件作锚点，其余按问题返回；也允许平等交替，不必均分时长。

## 每件画独立核对

为每件作品分配稳定ID，分别记录标题、作者著录、年代或范围、媒介、尺寸、收藏机构、具体版本、来源URL、访问日期、图像许可和画心边界。不要把一件作品的署款、鉴藏印、尺寸、画家生平解释或技术分析移给另一件。同名系列、摹本、工坊作、传属和局部复制分别标识。

建立简短比较表：`比较轴 → 甲的可见局部与来源 → 乙的可见局部与来源 → 能说到哪一步`。其中“本片观察”“馆方事实”“历史关系证据”分开。精确年份不明时用范围；没有证据证明影响时只说“并置来看”，不画虚假的师承箭头。

例：可从[范宽《溪山行旅图》馆方页](https://theme.npm.edu.tw/selection/Article.aspx?sNo=04000959)与[郭熙《早春图》档案](https://digitalarchive.npm.gov.tw/Collection/Detail/47?dep=P)组织“两幅山水，视线怎样走进去？”的比较。2026-11-02核对到两幅画分别为206.3×103.3与158.3×108.1厘米；这些数值只属于本例，不能套给后续作品。山体、行旅与烟岚的具体旁白仍须打开实际高清图定位。这是选题/分镜示例，不是已制作的多画成片。

## 比较镜头要公平

- **先认识作品，再比较局部**：每件主作品首次进入时短暂给出全貌与可读标题；局部切换时通过标题或固定身份提示维持归属。需要持续细读的主作品，在其首次持续细读前建立尺幅，可用一张共同尺度板一次完成。
- **原尺寸与构图归一化分开**：共同尺度板用同一像素/厘米比例，参照人也统一；构图对照可独立缩放以看清，但标“构图对照，非同比例”。不要把等高排版说成实物一样大。
- **同一问题对应同一位置**：比较视线入口就同时标入口；比较笔触要到双方可见的表面细节，不拿甲的超清局部对乙的缩略图下结论。
- **并置与交替结合**：横版适合左右分屏；竖版可上下配对或保留一幅小身份图，再交替占主屏，避免两幅都缩得无法观看。3:4同样按手机预览决定。
- **保留原画比例和色彩语境**：不用拉伸、镜像、鱼眼或生成修补凑对应；不同摄影、老化与扫描条件下的数字色彩差异，不直接等同于颜料或作者意图差异。
- **AI段分别绑定作品**：每条参考、生成和归属均可追溯；混合两画的创意演绎应独立标明，不冒充中间版本、复原或影响证据。比较结论落在原图上，生成数量按叙事需要决定。

封面围绕共同问题选择一主一辅或清楚的双画构图，标题不堆作品名。图像拼接/生成重构不造成“原画本来同处一幅”的误读。资料、音乐和图像使用条件逐件保留，公开正文仍尊重用户的工具介绍偏好。

## 可选计划格式

[双画趣味比较草案](../examples/multi-artwork-playful-plan.json)给出一次约90秒的原画比较编排与动效提示；无媒体、无新增配音，不是已经渲染的成片。

保留旧单幅计划的`artwork`与`asset_id`格式。多作品计划改用：

- `artworks`：至少两件，唯一`id`以及`title`、`artist`、`sources`；可增加馆方归属措辞、尺寸、年代、版本等记录。不同时保留顶层单幅`artwork`。
- `comparison`：`mode`为`same-artist/cross-artist/relationships`，`question`为全片问题，`axes`为比较轴的非空字符串数组。模式是创作路线，不是已经证实的作者或历史关系。
- `assets[].artwork_id`：每条原图或AI图像/视频绑定具体作品ID；图形、贴纸和声音可独立，不伪装为原画。
- `shots[].asset_id`：普通单主画面；或`asset_ids`：并置的原画证据数组，两者只能选一个。贴纸、字幕等辅助层写进镜头备注和实际合成工程，不放进证据数组。
- 涉及不同作品的分析并置镜头填`comparison_axis`，并用`labels`记录各作品ID对应的屏幕身份文字。先将全貌缩为等高再比较局部，并不能据此宣称尺幅相同。
- `editing_style`可选`contemplative/playful-art-history`；镜头`notes`可包含贴纸、运镜、关键帧、音效落点和阅读停留。例子里的预估时码须按实际配音重排。

运行原有`scripts/validate_plan.py`即可。检查器验证作品/素材引用、并置标签声明和原画证据关系；不验证作者归属、尺寸比例、标签是否真实渲染、贴纸时码或实际阅读速度。原有单画案例继续有效，已有多轨剪辑也不强制迁移格式。
