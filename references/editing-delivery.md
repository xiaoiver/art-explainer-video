# 剪辑、导出与交付

## 保持后续可编辑

保留原始画作、裁切配置、已选生成片段、独立声音轨和字幕时码。需要原生字幕精剪时输出无烧录字幕的画面底片，避免叠出两层字；声音也从独立轨导入，不再叠加底片的混音。

编辑器工程不能代替可恢复的输入规格。记录素材路径、时间线和字体设置；在原生应用可能加密工程时，打开前保存输入配置与明文快照，并区分其与最终原生工程的状态。

## 剪映兼容性与实际预览

调用 capcut-edit 时读当前技能与 CLI schema。修改现有草稿前备份并关闭原生应用中的当前项目，避免覆盖缓存。遇到加密或不可读工程，不尝试解密、随意降级或强制写入；可在授权范围内新建工程，或者通过原生界面续改。

用 CLI 生成工程后，实际在桌面版打开验证。CLI 代理渲染不等于剪映原生导出，不能混称。软件显示名、可执行文件名和 bundle 可能不同；应用列表查不到时依据实际安装信息定位，而不是反复猜名。

字幕按意群拆分，检查作品名和停顿。原作纹理复杂时需要轻微描边或阴影。少量关键词强调即可，避免频繁跳字、炫光和抖动妨碍看画。

导入规格中的描边、阴影字段可能存在，但原生界面开关仍未启用。《雪中猎人》曾出现这一情况，雪地白字对比不足；已通过原生多选全部字幕显式启用并验证。不能只凭 JSON 字段判定样式生效；尤其检查白雪、浅绢等明亮背景。换方向时也重新核对字幕区域，参见 [横竖版](formats.md)。

《溪山行旅图》的本机横版 CLI 字号10在剪映中明显过大，真实预览最后改为界面字号5；《雪中猎人》的本机竖版初始字号4又过小，重新校准为8。小数输入还曾被控件去掉小数点。**这些数值只描述对应画布和版本，不能当作新工程默认值。** 调整后读取实际控件和画面，换方向或跨版本重新校准。

多选文本轨或切换弹窗后布局可能改变。每次重要操作前重新读取界面；用户切换应用、渲染结束、导出页变化后不复用旧坐标或元素序号。

## 已有成片增加段落

先在原旁白和字幕的自然停顿处找插入点，再以新增配音的实际时长安排看画空间。后续画面、三类声音轨与字幕一起顺延；跨过插入点的缓推镜头拆分时保持原裁切进度，不让镜头突然跳回起点。检查时间线覆盖、字幕重叠和声音接缝。

保留旧成片与旧工程，给新工程和导出明确版本名。同步更新脚本、SRT、发布文案中的片长、素材来源和制作记录；方案文档的状态要与实际成片一致。只改声音和题款镜头时复用已选动态，无须重生成整片。参见 [《早春图》20秒插段](early-spring-case.md)。

## 本地导出的操作边界

1. 在导出页确认目标路径、尺寸、帧率、音频设置，并关闭未获授权的云备份选项。
2. 启动导出，观察进度；导出结束后先刷新界面状态。
3. 用本地文件检查确认导出成功。不要通过回车去“确认完成”：焦点可能已落到上传或分享按钮。
4. 直接关闭分享页；只有用户另外明确授权才进入平台上传、账号登录或发布。

如果发生意外传输，停止并如实记录可见传输量、是否登录、是否提交发布及未知项。不能因为未发布就声称从未上传，也不能在没有证据时声称服务端已删除。

## 验收与制作记录

最终视频检查实际流信息与完整解码，按镜头取帧核对构图、原画边界、生成标记、字幕位置和转场。复杂技法讲解的局部必须回查原图。声音检查最终编码文件，并安排可执行的听音确认。

完整解码通过仍可能有渲染闪白。《雪中猎人》竖版抽帧发现画面区偶发单帧空白，随后对整片画面区逐帧检查低方差候选，排除开头结尾的设计淡化，再逐一确认并修复。低方差本身不是错误证明，留白、雪地与静态画作都可能被误报；这种检查用于已出现类似症状的工程，不替代观看。

封面单独读取尺寸、文字和缩略图效果。发布文案附资料出处，清楚说明生成画面和声音的范围。写文案、做封面或本地导出不包含向社交平台提交内容的授权。

交付包可包含 `final.mp4`、字幕、画面底片、分轨音频、工程 / 可恢复配置、封面、发布文案与制作记录；按用户需求选择，不要求每次产生全部文件。

制作记录用事实填写，建议保留以下字段：

| 项目 | 内容 |
| --- | --- |
| 状态 | 当前交付、待完成内容、已批准版本 |
| 资料 | 馆藏来源、图像出处、查证日期、具体讲解点；使用题印时附释文、题写者或印主、年代、原图位置与不确定项 |
| 素材 | 原画 / AI / 自制图文，工具模型，参考来源，选用状态 |
| 创作选择 | 脚本、画风、音色样本、用户授权的后续自主范围 |
| 编辑 | 时间线、字幕分句、分轨声音、字体和关键预览修正 |
| 工程 | 软件版本、输入规格、备份阶段、原生保存状态 |
| 导出 | 实际媒体信息、解码和响度结果、是否为原生导出 |
| 验收限制 | 哪些已看、已听；哪些仅经转录、波形或元数据检查 |
| 发布 | 封面比例、标题文案、AI 标注；实际是否上传或发布 |

不要在向外共享的记录中包含密钥、本机私人目录、私人素材标识或平台内部响应。出错经验写成对应操作的具体防范，不把个别事故扩展成与任务无关的长审批流程。
