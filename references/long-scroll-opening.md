# 长卷开头：先让画展开

适用于横向长卷，尤其是把整卷缩进画布后只剩一条细带的情况。先让观众看清人物、衣纹和建筑，再解释卷有多长。它是原画上的摄影机运动，不需要重新生成视频；不套用到所有立轴、肖像或油画。

## 观看与尺幅的顺序

优先采用“大画面缓慢浏览一段 → 短暂完整尺幅 → 逐处细读”。开场只提出观看问题、交代作品名，不在尺幅之前展开技法、人物身份等持续分析。尺幅仍应紧接浏览，不能拖到片尾。详见 [尺幅要求](art-direction.md#尺幅)。

开场画面尽量满宽，保留画心的主要高度；小标题、章节栏和字幕留在各自安全区，不让大标题压过原画。满宽不等于拉伸或覆盖字幕区，也不要求展示完整卷长。完整全卷仍可在尺幅镜头里短暂缩小。

时长取决于旁白和可见细节。先选一段能在舒缓速度下看清的连续画面；整卷过长时缩短浏览范围，或确有需要再延长开头。不要在十几秒内快速扫完五六米长卷，也不要无目的来回往返。中国手卷通常从右向左观看，仍须核对该件作品的实际顺序；字幕和画作本身不得镜像。

横版、3:4、9:16都可以采用此法。换画幅时重新计算视窗、取段和字幕区，不能照搬横版坐标；竖版视窗更窄，可能只需浏览更短的一段。

## 素材与拼接

先用馆方完整高清文件或同一图像服务的连续区域。总像素宽不代表高度足够：全卷只有几百像素高时，放到大视窗会暴露模糊，应查同一作品的分段高清照片。

需要拼接时，核对为同一件、同一版本、相邻且确有重叠的照片。裁掉色卡、摄影边缘与装裱，以共同细节做平移或小幅相似变换，处理重叠区并裁出无空洞的共同有效画面。检查接缝处栏杆、屋柱、人物和笔线是否重影、重复或缺失；不可靠时改用分段切换。不要用生成补绘或强行形变填缝。

记录来源图、画心裁切、排列顺序、对齐方法、变换、输出像素与浏览范围。分段浏览图标“原画分段拼接浏览”，只拼了一段就写明它不是全卷母版。题款和技法判断优先回到单张馆方摄影。几何拼接与 AI 演绎在记录中分开；来源署名和使用条件仍需保留。

## 等比平移

源图为 `Iw × Ih`，视窗为 `Vw × Vh`。以高度等比显示时：

```text
scale = Vh / Ih
displayWidth = Iw * scale
travel = displayWidth - Vw
```

`travel <= 0` 时没有横向浏览余量，换合适取段或静态完整展示，不制造空白移动。先以 `travel / duration` 估算平均屏幕速度，在实际手机大小预览细节停留是否足够；缓动也有更快的中段。

从右向左观看意味着先看图的右端，图层本身向右移动：`left` 从 `Vw - displayWidth` 到 `0`。反向浏览则相反。用轻缓进出或近匀速，不加弹跳、旋转和突然变焦。

可复制 [LongScrollPan.tsx](../assets/long-scroll/LongScrollPan.tsx) 与同目录的 [几何函数](../assets/long-scroll/layout.ts) 到 Remotion 工程，使用 [本片参数](../examples/hangong-opening.json)：

```tsx
// config 按 LongScrollPanProps 读取并核对；src 必须解析成实际 URL。
<Sequence from={0} durationInFrames={config.durationInFrames}>
  <LongScrollPan {...config} src={staticFile(config.src)} />
</Sequence>
```

组件用 Sequence 的局部帧；`durationInFrames` 应由实际剪辑边界 `round(end * fps) - round(start * fps)` 计算。标题、章节和字幕放在移动图层外。组件只做裁切与平移，不生成画面、不安排转场，也不替代来源核对。先确认图片实际尺寸与传入值一致。若编排工具只暂存 TS/TSX 源文件，将配置作为 props 传入，或明确暂存 JSON，避免因 JSON import 缺失而打包失败。

## 衔接与验收

满幅画面接尺幅、并列图等不同布局时，让整个新布局连同不透明底色一起淡入；只淡入新图文会让旧满幅画面继续透在背后，最后突然消失。单镜大字在交接前退场，章节栏保留为独立固定层。按片子节奏选转场长度，不把本片的12帧写成固定规范。

检查最终文件的开头、中间、结束、接缝经过处，以及转场前后：画心没有空洞、拉伸、摄影边缘或无意裁断，人物细节在手机上可读，文字不抢画面；尺幅能配合旁白报完长宽。更换开头时保存旧成片，另建版本；已选旁白、BGM、环境音和后段动态能复用就复用，声音时长没有变化时不重生成。

## 火后分藏，不是照片接缝

有的长卷今天分藏两处。影像里重新并排，并不等于馆方把原纸裱回一卷。《富春山居图》前段《剩山图》、后段《无用师卷》即是如此：1650年火后分装，2011年台北故宫「山水合璧」同柜并列，没有永久重裱。手卷仍从右向左，剩山左缘对无用师卷右缘，历史切口保持可见。骑缝印与火痕用真迹。厘米级填缝或卷首佚失若用生成画面，须标「AI 笔墨延展」或「AI 想象演绎」，且不能充当披麻、苔点等证据。这和上面的馆方分段照片重叠拼接是两件事：照片空洞不用生成补绘去填。详见 [《富春山居图》](fuchun-shanju-case.md)。
