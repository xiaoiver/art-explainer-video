# 案例：《荷石水鸟图》——翻白眼的鸟，在瞪你


## 实际制作与语速修订

2026-11-03制作。视频最终v3为16:9、1920×1080、24fps，实测60秒、1440帧、13镜头、36条解说字幕；封面独立3:4、1728×2304。下方8镜JSON仍是单画配音前提案，不代替此时间线。

v1为35.625秒。用户观看后认为语速太快，并要求片尾不用提Gallery Mate。v2恢复不快于原始配音的节奏，较快段落控制在约4.15汉字/秒；原四段含停顿的测量值为3.53、4.08、4.15、4.15字/秒。片尾停在“看展之前，先读懂他的眼神”，删去品牌口播、品牌画面与引导打开的句子。语速按用户实际反馈调整，前一集趣味艺术史要快，不等于每幅水墨作品都要用相同语速。

用户随后要求补充画鱼的作品。v3加入故宫藏《鱼石图》轴（新00076950），新增一段旁白和三个镜头，语速约3.05字/秒。通过“同一种眼神”连接两画，原来的单画主线仍是锚点；不将“最有名”作为未经证实的排名，也不因同一艺术家就说这两幅一定同属一个系列。

原四段及新增鱼图段旁白由YouMind/Seed Audio生成，复用已选合成音色参考。v2片尾从原始音频的停顿区剪去品牌句，没有重复下单。字幕采用平台实际返回的秒级转录与意群内分配，选用段落文字与修订脚本一致；没有逐字强制对齐或独立ASR验收的声明。

新配乐生成被供应商输出审核拒绝，没有生成文件，未重试。实际复用《瑞鹤图》此前已选的“天青疏弦”纯音乐未duck底轨，原速取段后按本集旁白重新做一次避让。纸张滑动与鼠标点击为此前已核CC0的真实录音，保留来源性质、线性增益和声点时码；不把它们写成新生成的毛笔录音。完整试听不以转录、波形或响度数据代替。

使用固定版本Open Montage调度、原生自写Remotion构图与FFmpeg字幕合成。画面标题与导航在底片内，需改源码重渲染；解说字幕和三条声音轨在剪映工程中独立可编辑。运行版本、来源和本机路径留在本地制作记录，仓库不含原画母版、声音参考链接或密钥。

系列是 Gallery Mate《读画》／奇趣美术馆。语义脚本 id 为 `gallery-mate-bada-heshi-shuiniu`。口播经本轮重新分句，原稿144个汉字；本轮重写后先按约40秒安排，再依实际配音重排。情绪线是倔而静、少才有力、白眼向人。不把遗民政治史写成讲义。

本提案选择横版；这是该集选择，不代表系列统一比例。立轴在 16:9 里可以左画右人，眼部推镜仍能满幅。封面不跟视频同一比例：3:4 留给立轴和标题的竖向留白。没有改成 9:16。

本集锁定故宫博物院藏朱耷《荷石水鸟图》轴，文物号新00146234。近题荷石、荷花、水鸟不要混用素材。仓库不分发母版；下面的图片地址只是页面或直链，不是入库文件。

馆方人物小传写：明宗室宁献王后裔，南昌人；清顺治五年（1648）落发为僧；康熙二十三年（1684）始号八大山人；晚年把「八大山人」连缀来写，似「哭之」，也似「笑之」。法名一页作「传棨」、一页作「传綮」。旁白只说到出家后号八大山人，不报法名，不展开号的几种考释。

「白眼」是本集对眼部的观看句：眼珠顶到眼眶上沿。它不是把《枯木寒鸦图》页上的「白眼向人」挪到本轴。1200 像素宽的 Commons 预览只够核对构图，不够定眼珠位置。开拍前用名画记放大再看一眼。

同一张预览能看见：右上大块墨荷压下来，中间和左侧大片空纸，下腹一块危石，石上一只缩着的单脚水鸟，左上款书和两方朱印。这和定稿「空、压、少」一致。款是否连着「写」、印文是否即「虚斋珍玩」，仍以藏品页加高清原图为准，不凭预览识读。

## 语义脚本与镜头绑定

脚本正文没有秒数、路径或模型名。Selections：`baiyan`、`composition`、`bada`、`kuzhixiaozhi`。Moments：`eye-lock`、`shaoli`、`renshi`。

```text
script: gallery-mate-bada-heshi-shuiniu

hook:
  这只鸟，怎么像在翻白眼？
scale:
  先看全幅：画心高一米二十七。
eye:
  再看眼睛，黑眼珠挤在上边，下面却留着白。
painting:
  大片纸都空着，墨荷却从右上压下来。危石上，只缩着一只单脚水鸟。笔墨少，气势一点没少。
who:
  画家叫朱耷，出过家，后来用八大山人署名。
signature:
  这几个字连起来，像哭之，也像笑之。再回头看这只鸟，安安静静，却很有脾气。
outro:
  按上博年度计划，十二月东馆将迎来八大山人大展。看展之前，先读懂他的眼神。打开 Gallery Mate，我们慢慢读。
```

## 修订后的观看顺序

眼部只起问，接着立刻建立全幅与尺度，再进入持续局部分析。保留尺幅时遵循[画面与脚本](art-direction.md)：不是等到片尾前才补，也不把长卷浏览例外误用为所有题材的放宽。

127cm约为170cm参照身高的74.7%，不能说“约一人来高”。口播改成“画心高一米二十七”，独立人物与原画等比排布，注明“按馆方尺寸示意”。未记录装裱通高，不拿画心高度代表装裱尺寸。

| 镜 | 配音前预估 | 作用 |
| --- | --- | --- |
| s01 | 0–3秒 | 原画眼部起问 |
| s07 | 3–6秒 | 全幅与自然比例成人参照 |
| s02 | 6–10秒 | 眼部细读 |
| s03 | 10–18秒 | 留白、墨荷、危石与鸟 |
| s04 | 18–21秒 | 少与有力，短停留 |
| s05 | 21–26秒 | 作者与款署 |
| s06 | 26–32秒 | 署款形态、回看眼神 |
| s08 | 32–40秒 | 上博未来展览计划与落版 |

这不是实测成片时间线；实际配音后调整。横版1920×1080、24fps与3:4封面保持不变。字幕继续宋体，短标题与吐槽分层；不因沿用节奏而把古画封面套成现代展示字。全幅落版标明故宫博物院藏、文物号新00146234、纸本墨笔、127×46cm及实际图像来源。

## 本计划不设生成画面

白眼、空纸、荷石、款印和尺幅都用原画。没有 AI 镜头。若以后要一段水墨气氛，整段标「AI 笔墨延展」或「AI 想象演绎」，`purpose` 用 `atmosphere`，并且能整段删掉。它不证明眼位、款署、印文或厘米。
