# 案例：《荷石水鸟图》——翻白眼的鸟，在瞪你

## 当前状态：制作前提案

2026-11-03 整理的资料与 8 镜分镜计划。状态是制作前提案：尚未下载母版、申请故宫影像授权、录音、生成画面或剪辑成片，也未上传或发布。计划中的视频为 16:9、1920 × 1080、24fps、60 秒；封面独立 3:4、1728 × 2304。配套 [8 镜计划](../examples/bada-heshi-shuiniu-plan.json) 不含媒体、私人目录、平台任务链接或音色参考。表内时码是配音前的预估，不是成片验收。

系列是 Gallery Mate《读画》／奇趣美术馆。语义脚本 id 为 `gallery-mate-bada-heshi-shuiniu`。口播正文约 190 字（含标点与 “Gallery Mate”），目标约 60 秒。情绪线是倔而静、少才有力、白眼向人。不把遗民政治史写成讲义。

视频用横版，与已发布《读画》成片一致。立轴在 16:9 里可以左画右人，眼部推镜仍能满幅。封面不跟视频同一比例：3:4 留给立轴和标题的竖向留白。没有改成 9:16。

本集锁定故宫博物院藏朱耷《荷石水鸟图》轴，文物号新00146234。近题荷石、荷花、水鸟不要混用素材。仓库不分发母版；下面的图片地址只是页面或直链，不是入库文件。

馆方人物小传写：明宗室宁献王后裔，南昌人；清顺治五年（1648）落发为僧；康熙二十三年（1684）始号八大山人；晚年把「八大山人」连缀来写，似「哭之」，也似「笑之」。法名一页作「传棨」、一页作「传綮」。旁白只说到出家后号八大山人，不报法名，不展开号的几种考释。

「白眼」是本集对眼部的观看句：眼珠顶到眼眶上沿。它不是把《枯木寒鸦图》页上的「白眼向人」挪到本轴。1200 像素宽的 Commons 预览只够核对构图，不够定眼珠位置。开拍前用名画记放大再看一眼。

同一张预览能看见：右上大块墨荷压下来，中间和左侧大片空纸，下腹一块危石，石上一只缩着的单脚水鸟，左上款书和两方朱印。这和定稿「空、压、少」一致。款是否连着「写」、印文是否即「虚斋珍玩」，仍以藏品页加高清原图为准，不凭预览识读。

## 语义脚本与镜头绑定

脚本正文没有秒数、路径或模型名。Selections：`baiyan`、`composition`、`bada`、`kuzhixiaozhi`。Moments：`eye-lock`、`shaoli`、`renshi`。

```text
script: gallery-mate-bada-heshi-shuiniu

hook:
  见过翻白眼的鸟吗？眼珠顶到眼眶上沿——八大山人的招牌眼神。
painting:
  《荷石水鸟图》里，大半幅是空的：墨荷从上压下，危石上缩着一只单脚水鸟。少，才有力。
who:
  他是朱耷，明宗室后人，出家后号八大山人。款署连写，像哭之，也像笑之。这只鸟，又倔又静。
scale:
  立轴约一人来高——你站在画前，先被留白和那只白眼盯住。
outro:
  南昌「高山仰止」、北京「可得神仙」，周年展里也能遇见他。打开 Gallery Mate，我们慢慢读。
```

## 计划中的观看顺序

长卷模板是先浏览再报尺幅。这一支 60 秒短片按定稿顺序：白眼、空与压、人、人尺、片尾。人尺不塞进落版，单独是 s07，主画面是原画全幅。它不在开场后第一镜，因为钩子必须先是那只眼。

纵 127 厘米约为 170 厘米参照身高的四分之三（127/170）。剪影要比画高，不能把画拉到与人同高。两页都没有装裱通高，示意只对所报的 127 × 46 厘米。画面写「纵 127 × 横 46 厘米 · 按馆方尺寸示意」。画里的鸟不能代替纸的尺寸。精确厘米只出现在比例尺和字幕，口播不念数字。

| 镜 | 预估时码 | 主画面 | 作用 |
| --- | --- | --- | --- |
| s01 | 0–8 秒 | 原画眼部缓推 | 钩子。核对眼珠是否顶到上眶之后再配这句 |
| s02 | 8–11 秒 | 同一眼部定住 | 被盯住的一拍 |
| s03 | 11–22 秒 | 原画全幅，自上而下 | 空、墨荷下压、危石单脚鸟 |
| s04 | 22–26 秒 | 原画荷与石 | 「少，才有力」 |
| s05 | 26–34 秒 | 原画款印区域 | 朱耷，出家后号八大山人 |
| s06 | 34–42 秒 | 款书连笔 | 哭之／笑之。鸟又倔又静 |
| s07 | 42–52 秒 | 原画全幅，旁侧叠加成人剪影 | 人尺。早于片尾，晚于钩子 |
| s08 | 52–60 秒 | 全幅静止，再黑场落版 | 馆藏署名。展名只是弱字幕，不念文物号 |

配音之后按实际音频重排时码。音乐让位给讲解。落版至少写：`清 朱耷（八大山人）《荷石水鸟图》轴　故宫博物院藏　文物号新00146234`，以及 `纵 127 × 横 46 厘米`。若用 Commons 工作底图，另写图像来自 Wikimedia Commons，馆藏与尺寸以故宫藏品页为准。这句话不代替书面授权。

## 本计划不设生成画面

白眼、空纸、荷石、款印和尺幅都用原画。没有 AI 镜头。若以后要一段水墨气氛，整段标「AI 笔墨延展」或「AI 想象演绎」，`purpose` 用 `atmosphere`，并且能整段删掉。它不证明眼位、款署、印文或厘米。

人尺剪影用仓库里已有的原创侧立人形，见 [尺幅参照人物](scale-reference.md)。它是 graphic，不是 s07 的主画面，也不是展厅照片。

## 开放缺口

1. **版本**：本集视觉参照只认新00146234。眼位、款末「写」字和「珍玩／秘玩」都要在高清原图上再核一次。Gallery Mate artifacts DB 还没有这条藏品，不要编 CDN 地址。
2. **授权**：名画记与 Commons 都还不是本片的授权母版。发布渠道定了再决定是否另申请故宫影像。
3. **片尾范围**：展名用「高山仰止 墨染千秋」。国家文物局通稿写过本轴画名曾在江西省博物馆该展出现，口播不跟着念文物号或同展其他作品。荣宝斋截止日仍有差额：资料清单写到 2026-09-01；2026-08-26 [北京日报稿](https://peking.bjd.com.cn/content/s6a8eec10e4b03fa51a836c35.html) 写展期延至 2026-09-30。口播不念日期。
5. **生年与法名**：1624 与 1626、传棨与传綮，旁白都不采用。
6. **数字文物库**：上节那条静态页没有尺寸，不能拿来改 127 厘米。
