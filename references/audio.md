# 声音制作与时码

## 音色选择与延续

先用两三句包含停顿、作品名和长短句的旁白试音。描述年龄感、共鸣、语速、克制程度和普通话表达，不用具体真人名字作模仿目标。用户反馈“再老成一点”时调整这些特征，保留此前获认可的方向。

将被选中的合成音频保存为音色参考，记下脚本、模型、提示词和实际时长。后续旁白引用该音频及相同表演描述，段间留剪辑余量。本次批准开头被直接复用，再生成续段；无须为追求整齐重新生成已通过内容。

示例描述需按用户选择改写：

> 成熟、沉稳的中文男声，中低音区，温润但不沙哑。像坐在画前平静地讲述，停顿自然，句尾收住，避免播音腔和夸张感叹。保持参考合成音频的音色与语速。

技术检查不能替代用户试听。如果没有实际听音能力，明确报告仅检查转录、波形与响度，不写“已听过、自然无瑕”。

## BGM 与音效

人声、音乐、环境与事件音效分别生成和保存。音乐风格由画作与解说节奏决定；古琴只是本次水墨山水方案，不是所有古画的标准配乐。

需要纯器乐时明确“无主唱、无哼鸣、无口白”。自动转录出现叹词只是可疑线索，可能误识别乐器；安排试听或保守更换可疑片段，不宣称转录证明有人声。

提示词要求的长度不保证实际长度。先探测原文件，再选择重生成、剪接或循环。循环点避开明显乐句中断，以适合余韵的短交叉淡化衔接，不机械复制同一段。音效跟随镜头出现，避免把绘画中的静态细瀑做成轰鸣瀑布。

## 旁白决定镜头时间

先检查原始音量。本次原始人声很轻，直接用固定 −34 dB 静音阈值会把大量有效讲话当成静音。可在工作副本上归一化后再找停顿，或采用相对阈值；保留原始音频。

平台分句转录仅提供粗时码时，用实际波形和停顿修正字幕。只有运行过相应工具才称为逐词强制对齐。拆意群后与获批脚本逐字核对，保留名词和语义完整性。

## 混音与检查

人声优先，句间才适当抬高音乐；压低配乐时检查攻击与释放时间的单位。不要叠加两个已经做过相同 ducking 的版本。

单独检查开头、插入段和正文的声音层次，整片响度正常仍可能开头偏空。遇到“开头没气氛、后面合适”的反馈，先看环境音是否延迟进入、琴声是否选在长余韵或静音处、淡入和侧链是否叠加压得过低；按需要更换开头乐句、提前轻铺环境音，再渐接已合适的正文。各轨同一时间窗的均方根可辅助定位，不能替代试听，也不要把案例的绝对电平当作通用目标。实例如 [《早春图》开场修订](early-spring-case.md)。

约 −18 至 −16 LUFS、真峰值保留约 1–2 dB 余量可作为本类解说的起点，最终按平台要求、素材动态和试听调整，不作为统一合格线。测量最终编码文件，区分输入实测和归一化预测值。

可按当前工具能力使用以下检查（路径替换成自己的文件）：

```bash
ffprobe -v error -show_format -show_streams -of json final.mp4
ffmpeg -v error -i final.mp4 -f null -
ffmpeg -hide_banner -i final.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json -f null -
```

最后一条用于分析，不覆盖文件。完整解码和响度数据仍不能证明发音、音乐与画面情绪符合要求；这些列入实际试听验收。
