# 字体与文字层级

先按文字的作用分工，再选择字体。用户已认可底部解说字幕的宋体观感，希望标题和标注更有区分度；2026-10-30同意将以下搭配记入本系列的制作方法。这是后续制作的选择，不代表《汉宫春晓图》现有成片已更换字体，也不要求所有画种或其他用户采用同一组合。

## 本系列的搭配

| 文字角色 | 字体选择 | 排版与使用 |
| --- | --- | --- |
| 底部解说字幕 | 保留已选宋体；本系列为Songti SC | 保持已认可的字号、暖白、轻描边与阴影，按意群分行，优先耐读 |
| 提问、镜头短标题 | 得意黑为已实践方案；可按风格另选展示字 | 用于短句和观看提示，提供亲近、有活力的语气；不铺满全片或套到连续长段 |
| 章节导航、尺寸、年代、来源 | 简洁的常规黑体 | 用本机可用且有合适使用权限的字体，常规字形保证小字与数字清楚；项目内固定选择 |
| 题跋、题款的现代释文 | 宋体 | 标明释文排录、题写者与年代，与现代讲解标题及原迹分别呈现 |
| 「名画开小差」固定字标 | 思源宋体CN SemiBold（600） | 已确认版本保留“差”字迟到、旧金色与轻微倾斜；成品及可编辑参数见[系列片头](series-intro.md)，不套用得意黑短标题规则 |
| 古画封面标题 | 优先传统宋体或相近书卷气字形 | 本系列2026-10-31确认的偏好；与纸绢留白共同构图，和视频得意黑短标题分别选择 |

例如“她们在忙什么？”“再看这张棋桌”可用得意黑；底部对应旁白继续使用原宋体。古画原迹、署款与印章保持原图，不用字体替换成貌似原迹的字。

字体区分配合字号、字重、留白、行距与位置：短标题醒目，字幕稳定，资料标注安静清楚。按用户需要扩展字族选择，让每款承担明确角色；同一信息保持可辨认的排版，跨镜变化仍有锚点。沉静山水可以减少得意黑出现的次数；新项目已有字体方案时尊重原选择，不为了采用本例另开一轮确认。

## 字体来源与落地

得意黑字身偏窄、带倾斜，并含美术字细节；适合本例短标题。下载与字形说明见 [官方仓库](https://github.com/atelier-anchor/smiley-sans)，授权为 [SIL OFL1.1](https://github.com/atelier-anchor/smiley-sans/blob/main/LICENSE)。需要时从官方发布获取字体；本技能不要求自动安装或额外购买字体。随项目分发字体文件时保留相应版权和许可文件，系统字体的使用与再分发条件另行核对。

记录每个角色的字体名称、实际字体文件或可恢复来源、版本、字重、字号、行距、字距、颜色及备用字体。字体不存在或缺字时选择有依据的替代并记录，不把回退渲染称为得意黑已生效。人名、繁体题跋、生僻字、数字和标点需用本次实际文本核对。

Remotion使用字体文件时，完成注册和加载后再开始截图或渲染，避免浏览器回退字体。剪映按实际字体名称与预览检查；不同画幅和软件里的字号不能直接互抄。保留字体原有比例与倾斜，不为凑行宽强行拉伸或额外压斜。先缩短短标题或调整换行，再处理字号。

## 封面与可编辑性

封面先决定画字如何同底，再按融合效果、准确性和可编辑需求选择随图生成文字，或无字底图加实际字体。需要准确字体文件、系列稳定复用或可编辑文字时采用独立排字，并保留底图、文字、字体配置及合成源；独立文字层仍须融入原有留白。具体选择与已验证案例见[封面的画字融合](cover-design.md)。

模型随图绘出的“宋体风格”“得意黑风格”只是视觉描述，不能宣称使用了准确字体文件；文字已融入图片时，也不能称为独立可编辑文字层。《汉宫春晓图》两版封面、《千里江山图》封面v2与《富春山居图》横版封面v3均采用随图生成文字，不把独立排字设为所有封面的硬性步骤。

视频也区分字幕与其他图文：剪映独立字幕轨可直接修改；已烘焙在画面底片里的标题、导航和尺寸，需改合成源并重新渲染。记录实际可编辑范围，不把所有文字都称作剪映字幕。

## 验收

在最终文件和手机缩略尺寸检查：字幕耐读，标题与字幕有区分，导航和数据清楚；作品名、人名和释文无缺字、截字或意外回退，倾斜笔画与标点没有被文字框切掉。长标题、大数字和题跋另看完整分辨率。原生界面验证与JSON配置分开记录，具体见 [剪辑与交付](editing-delivery.md)。

采用[趣味艺术史](playful-editing.md)时，可增加短吐槽贴纸、漫画气泡和关键词击点，底部解说仍保持稳定；原文题款、现代排录和编辑吐槽分层。现代气泡不可伪装成艺术家真实引语，多作品身份与生成标记不随装饰层一起震动。

[编辑标注](editorial-annotation.md)里的年份、馆藏署名和短引文用常规黑体，下划线、荧光、圈和括号只标那几个字。底部解说仍是宋体。引文不要换成吐槽贴纸，也不要写成手写体来冒充原话。

## 趣味艺术史的设计字体试样

2026-11-02用户希望字体更有设计感。按“展示标题 / 吐槽 / 连续解说”分角色，字形、字距、错位色影、纸片构图和入场时序共同设计；连续解说继续保留已认可宋体，不靠每个字抖动制造速度。

莫迪里阿尼竖版小样试用[站酷庆科黄油体](https://github.com/google/fonts/tree/main/ofl/zcoolqingkehuangyou)作窄长几何标题、[霞鹜漫黑](https://github.com/lxgw/LxgwMarkerGothic)作马克笔式吐槽。两款已核对OFL1.1并保留许可；2026-11-03用户认可小样方向并要求制作完整版，作为本集已选搭配，非所有画作的统一默认。实际文本检查人名、瞳等字形和标点，在手机大小与运动落稳时预览。后续按反馈选择，不扩展为古画封面或系列固定字标的默认。


## 更多字体的实际搭配

2026-11-03用户进一步澄清希望使用更多字体。参考片可以归纳为宋体抬头与粗黑台词两种气质，实际选择仍可扩展到展示字、手写字与英文斜衬线；按内容需要选用，字族数量不作为统一限制。底部连续解说保留已认可宋体，封面继续遵循古画画字融合偏好。

《荷石水鸟图》试用以下六款，另保留Songti SC字幕。这是本集搭配，不是全部题材的固定字体表：

| 字体 | 本集任务 |
| --- | --- |
| 思源宋体CN SemiBold | 常驻抬头、作者名、展讯与传统封面 |
| Noto Sans SC Black | 白色重点短句，外缘与硬影分层 |
| 站酷庆科黄油体 | 开头眼神钩子、气质短句 |
| 霞鹜漫黑 | 手写吐槽纸片 |
| 得意黑 | 全幅观看提示与现代署名说明 |
| Playfair Display Italic | 作者罗马字名Zhu Da；独立字族，不为增加字体硬加英文翻译 |

先用本次真实文字做搭配板，再看实际镜头、封面缩略图与字幕。需要糙边时另加可控纹理，不能把普通字体加描边称作磨损字体。中文粗黑叠加浏览器文字描边可能显出字形内部轮廓，出现时改用外部阴影或字形遮罩并复查。

从Google Fonts取得的项目文字子集只覆盖请求的字符。改文案前检查覆盖范围，扩充子集或取得完整字体；记录官方来源、哈希与许可。不能将子集文件当作已安装完整中文字库。原生剪映与外部渲染分别检查字号，保留真实可编辑范围。
