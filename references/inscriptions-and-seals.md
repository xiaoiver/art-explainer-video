# 题跋与印章：画作在时间中的经历

适用于原作题款、后人题诗题跋、题签及鉴藏印中确有可讲故事的项目。研究时检查这些内容，是否进入成片由叙事价值决定；它们不必在每支短片中出现。

## 先判断故事的作用

优先选能回答一个具体问题的材料：

- 画名从哪里来，谁留下了作品的年代或赠予对象？
- 某位后来的观看者如何理解这幅画，其说法与画面有什么呼应？
- 作品如何流传、重装、分合或进入收藏？相关题印支持哪一段经历？

用一两处具体证据讲清一个故事，比罗列全部印章更适合短视频。没有可靠故事时，保留画面主线，不为了“有文化信息”硬加一个收藏家段落。

## 分清谁在什么时间留下什么

| 类型 | 讲解重点 | 易混淆处 |
| --- | --- | --- |
| 原作者款识 / 用印 | 自题画名、纪年、署名、赠予关系 | 今天通称的完整标题不一定逐字出现在原款中 |
| 后人题跋 / 题诗 | 后来的观看、评价、鉴定或纪事 | 后人读出的画意不自动等于画家的创作意图 |
| 题签 / 题籤 | 装裱、包首或签条上的名称和评价 | 不能指着画心说本来写在那里，也不能假定装裱从未更换 |
| 鉴藏印 / 收传印 | 印主与有依据的收藏流传关系 | 一方印不足以独立证明真伪、确切钤盖时间或印主亲见作品 |

先查馆藏著录和公开研究，再与实际原图核对。题写者、印主与镌刻者是不同身份，不混写。著录归属不确定时保留“据馆方著录”“传为”等限定，不把推测变成事实。

## 记录最少证据

为每一处拟使用内容记录：

`类型 → 释文 → 题写者 / 印主 → 年代及依据 → 原图位置 → 来源 → 故事作用 → 不确定项`

释文以可核对的机构著录或研究为依据，结合原图读字。OCR 仅用于检索，不能决定篆字、残字、纪年或印主；例如“壬子”容易被识成“王子”。简繁转换和标点整理不能改变字义。

不同机构或文章出现位置、印文和读字冲突时，回到图像及较可靠的著录说明差异。位置尚未核实就不作精确圈选；字不能可靠辨认时，可说明“馆方释作……”并展示局部，或暂不采用。

收藏故事还要区分“资料记载的传承”与“印章可见的线索”。不从印章列表自行拼出完整递藏年表，不编造赠画、失窃、争夺、帝王心理或盖印动机。若介绍相关争议，按来源标明其为研究意见。

## 放进视频的方法

先给全图位置，再展示原图局部，随后用可读字幕提供关键释文。放大时保持原始字形，避免插入 AI 重写或生成的印章。题字太小可在旁边排录释文，明确它是现代排录，不让观众误认原迹。

将不同年代的文字分开标记，例如“郭熙自题 · 1072”“乾隆题诗 · 1759”。题印故事结束后回到相应景物，让诗文或收藏线索帮助观看，而非遮住画面。

一次可从约 10–25 秒的短段落试起；这只是节奏建议，不是固定配额。若新增内容，按实际配音重新安排时间线和字幕，更新来源、成片版本与制作记录，不在旧视频未改时宣称已经加入。

## 《早春图》的选材示例

馆方著录郭熙自题“早春”及壬子年款，并列有“郭熙笔”印，可以解释画名和 1072 年的纪年；右上另有乾隆于 1759 年所题诗，其中“不藉柳桃閒點綴，春山早見氣如蒸”可以引回画中的烟岚与初春气息。这是两个不同时代的文字层次。

可用的叙述方向：郭熙留下画名；近七百年后，乾隆也从画中读到春意。后半句是基于题诗的阅读，不推断乾隆是否完全理解郭熙的原意。鉴藏印另有故事才选入，不把画上所有红印都归给乾隆。
