# 名画会说话：可选人物喜剧

只在用户选择人物短剧时读取。默认赏析仍按 [画面与脚本](art-direction.md)；这里让画中人用当代口语争取各自的目的，知识点在争执中成为筹码。借鉴《À musée vous, à musée moi》的画中人活过来、短冲突、开静收静，不复制节目台词、笑话、分集情节或演员声音。

## 从画中细节长出一场戏

1. 选能辨认人物表情、姿态和器物的原画。先从两个角色、一个细节、一个事实做 20–30 秒样例；人物太小或没有可演关系时，选另一幅画或沿用赏析，别强造人物身份。
2. 各写一句“他现在想要什么”，再写为了得到它会怎样说话。欲望是本片虚构设定；不能把真实模特的身份、亲属关系或作者意图随意编成史实。
3. 让画中物件、视线、站位或动作成为阻力。记录 `细节 → A 的目的 → B 的阻拦 → 知识点怎样改变争执 → 回扣细节的包袱`。换任何一幅画都能成立的职场段子，需要重写。
4. 按铺垫、反驳、升级、回扣写原创对白。两人要听见并回应对方；不要让他们轮流朗读百科。事实集中一两点，给观众看清原画的时间。笑话可以故意穿越，事实不穿越。
5. 分镜写明谁说、谁听、停顿、视线与动作。开场给原画，表演中安排反应镜头，结尾回到原画姿态。早期尺幅仍须在持续局部讲解前出现；过短放不下就缩减对白或加长，不跳过。

每个事实建立 `说法 → 馆方来源与访问日期 → 原图位置 → 原画证据镜头`。虚构动机、当代词语和包袱明确记作“原创虚构对白”。生成画面能演一句事实，但该事实仍另有原画镜头可核对；AI 不能证明人物历史心理、原作技法或实物大小。

## 表演与制作

先锁定左右人物、服装、持物、目光和画面轴线。声音按角色分别保存合成音色参考、表演描述和干声；不要模仿节目演员或其他具体真人。台词先试读，再用实际音频重排口型、停顿、字幕和切镜，不把 28 秒纸面计划当作实测时长。

生成镜头沿用现有 `ai-video` 素材与 `atmosphere` 用途，持续叠加可读的“AI 想象演绎 · 原创虚构对白”；未改动的全幅、局部和尺幅镜头使用 `original`。不要在原画证据层改嘴、补手、换表情，也不要把生成表演重新标作原画。片内文字由编辑器叠加，避免要求模型把字幕或资料卡画出来。

双人同时开口容易串声、串脸。优先一镜一句：A 说话时 B 闭嘴听，下一镜切 B 的反应再接话；单人说话镜头做口型，双人镜头只保留轻微反应。原画证据镜头可以继续听角色的画外音，原图保持静止。口型不可用时先交带角色标识、分轨对白的 animatic，明确“未做口型”，不假称验证完成。

生成提示词按镜头编写，例如样例的 s02（未实测）：

> 参考合法可用的《美国哥特式》原画，保留原作绘画质感、服装与左右人物身份。右侧持叉男子中近景，左侧女子安静听着；固定机位，男子只轻微挑眉、嘴部随已选男子干声开合，持叉手与背景稳定。他疲惫但认真地说：“拍个合照还得自带工具？我申请远程站岗。”句后留半秒让女子侧目。不要交换说话人、变成真人照片、改窗或新增手指。无配乐、无烧录文字；AI 标记在剪辑中叠加。

把参考图、角色、干声各自的用途写清，具体引用语法、时长和支持的输入以当前工具为准。不要把多个镜头硬塞进一次长生成。后续继续 [工具接入](tooling.md)、[声音制作](audio.md) 和 [剪辑与交付](editing-delivery.md) 的已有流程，Open Montage / Remotion 编排、剪映可选精剪。

### 外部参考与能力边界

- [dexhunter/seedance2-skill 的 Dialogue and Voice Acting](https://github.com/dexhunter/seedance2-skill/blob/main/SKILL.md#7-dialogue-and-voice-acting) 有双角色互怼示例，可参考角色标签与表演提示的写法。它是提示词资料，不是本模式依赖，也不保证双人生成成功；不照搬其中的对白。
- [Higgsfield 官方口型说明](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-lipsync-voiceover-and-aspect-ratios) 将说话镜头放在 Lipsync Studio，声音生成放在 Audio。Masterpiece 这类照片转名画预设解决造型转换，不等于双人喜剧或口型模板；先核对当前界面和模型能力，再选工具，不把预设名称当作能力保证。
- 节目形式参照 [ARTE 官方节目刊，第 8–9 页](https://artefrance-webmag.arte.tv/webmag/magazine/27-2017.pdf)。这里只借形式，不使用节目脚本作训练或改写材料。

## 28 秒双角色原创样例：《谁才是主角？》

作品：Grant Wood，*American Gothic*（《美国哥特式》），1930。资料及尺寸取 [芝加哥艺术博物馆在 Google Arts & Culture 的作品页](https://artsandculture.google.com/asset/american-gothic/5QEPm0jCc183Aw?hl=en)，查阅 2026-11-01。该页说明画名关联 Carpenter Gothic 农舍及其窗，并列尺寸 78 × 65.3 cm。人物只称“右侧持叉男子”“左侧女子”，不把真人模特关系套给剧中人物。图像下载、使用说明和高清坐标须在实际制作前复核。

- 男子想赶快结束摆拍、下班，策略是把手里的叉当作加班证据。
- 女子想让他站稳、维持合照，策略是让他注意背后房子的戏份。
- 持叉与尖窗引出“主角是谁”的争执；画名关联建筑这一事实让包袱转向“房子也该出工”。“远程站岗”“下班”“打卡”全是本片原创虚构。

| 时间 / 镜头 | 画面与动作 | 对白 / 声音 |
| --- | --- | --- |
| 0–3 / s01 | 未改动原画全幅；按馆方尺寸同比例叠加假定 170 cm 成人轮廓，标“78 × 65.3 cm；按馆方尺寸示意”。作品名、作者、年代简短出现。 | 无对白，轻环境底声。 |
| 3–8 / s02 | AI 男子中近景，持叉稳定；女子听完侧目。 | 男子：“拍个合照还得自带工具？我申请远程站岗。”末尾留反应停顿。 |
| 8–13 / s03 | AI 女子中近景，目光示意后方窗；男子闭嘴等着。 | 女子：“你先别挪，后面那扇尖窗才是主角。”重音在“尖窗”。 |
| 13–17 / s04 | 切未改动原画上方中央的尖拱窗，短标建筑名称；不做嘴部动画。 | 女子画外音：“画名里的哥特式，说的是房子。”这是要核对的知识点。 |
| 17–21 / s05 | AI 男子略抬眉，准备挪身；叉与手不变形。 | 男子：“那让房子拿叉，我下班。”句后留空。 |
| 21–25 / s06 | AI 双人反应镜头，女子回话，男子停住；逐渐恢复原画姿态。 | 女子：“它已经把尖顶带来了，就差你打卡。”留半秒让男子僵住。 |
| 25–28 / s07 | 切回未改动原画全幅，保留来源。 | 无对白，环境声收尾。 |

所有 AI 镜头持续标识“AI 想象演绎 · 原创虚构对白”。这张表与 [JSON 计划](../examples/american-gothic-comedy-plan.json) 是待制作示范；纸面秒数含预留停顿，尚未用真实音频或媒体验证。

## 计划检查与人工验收

可选 `performance` 对象与字段含义见 [计划文件格式](project-format.md#可选人物喜剧记录)。使用独立检查器，不改默认计划检查或引入风格登记表：

```bash
python3 scripts/validate_comedy.py examples/american-gothic-comedy-plan.json
python3 scripts/validate_comedy.py /path/to/plan.json --check-files --probe
```

它检查基础计划、人物动机字段、双人开口、台词与镜头时间、事实引用和原画证据关系；不会判断笑话是否好笑、史实真假、素材授权、口型质量或音色是否串人。交付前人工逐句核对事实，逐镜看持物、脸、视线、口型和标记，实际试听每人干声及混音；记录未验证项。制作、导出仍不包含社交发布。
