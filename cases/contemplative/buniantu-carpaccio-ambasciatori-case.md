# 案例：《步辇图》× 卡帕乔《使节抵达》——一次见面，谁在开口

状态：预制作资料 + 九十秒至两分钟口播稿（2026-11-13）。尚未配音、尚未分镜 JSON、未改 SKILL／styles。

## 选题一句

两边都把一场使节会见写成当场的礼仪。真正要看的不是「都在画使者」，而是一次见面，画面把「谁在开口」放在哪里：故宫这卷用手卷中间的空地，把会见收成一个对峙的瞬间；威尼斯那张用建筑把同一件事分成几段，最右边的房间里有一只正在比划的手。

## 镜头要点

- 开场钉住中间那片空地，一边是坐在辇上的人，一边是站着的三个人；局部 → 空地与对峙 → 全卷自右向左横移，再切到最右边房间里的手，往左看同一座建筑里的几段，观点后出。
- 必须让观众看见空地把会见切开，且手卷从右往左。不要用抬辇诸人的特写开场，不要把这卷讲成又一卷仕女。
- 人身高／尺幅对照只出一次：三十八厘米高、一百二十九厘米长，对这张画两百七十八厘米高、五百八十九厘米宽。出现在介绍卡帕乔的那一句。不要说「两人高」，不要让尺度成为本组「像」的主轴。
- 像／不像拆成两拍。分岔落在「一次见面，谁在开口」：是用手卷的空地把会见收成一个对峙的瞬间，还是用建筑把同一件事分成几段，把那只正在比划的手放在最右边的房间里。
- 「用建筑把同一件事分成几段来看」后留 1–2 秒静场，再进结尾的看画动作。
- 结尾是在辇和站着的三个人之间停住，看谁也不开口的那一块，再走到最右边的房间，只盯那只正在比划的手十秒，问一次见面，画面把「谁在开口」放在哪里。
