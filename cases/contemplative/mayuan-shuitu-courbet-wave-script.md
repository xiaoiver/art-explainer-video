# 九十秒至两分钟版｜马远《水图》与库尔贝《海浪》

系列意向：Gallery Mate《读画》中西对读。口播与画面不提 Gallery Mate／GM。中西并置是观看方法，不是影响史。

核对日期：2026-11-10。口播正文按这次定稿；制作备忘里的用词修正不改口播，除非成片前另定。

## 口播正文

[画面] 《秋水回波》底部，几乎被排齐的波纹。

这些线几乎像用尺子推出去的。这是水吗？

[画面] 拉到《秋水回波》半幅，再全幅。

是。它叫《秋水回波》，南宋马远《水图》卷里的一段。这一段只有一本杂志大小。底下那些波纹一行行排到天边，像在规定：回波该是这个样子。

[画面] 长卷横移：《长江万顷》，再《云生苍海》。

整卷专门画水。十二段，换一段，就换一套线。《长江万顷》是松开的钩；《云生苍海》把水推进雾里。除了偶尔一点点岩岸，几乎没有别的景物。水就是题目。

[画面] 《黄河逆流》浪头，切到库尔贝《海浪》刀刮的白。

再往右，是《黄河逆流》。浪头堆起来，第一眼已经很像另一张画。六百年后，库尔贝在诺曼底对着翻过来的海浪，用调色刀把白刮上去。

[画面] 两张并置，再拉开柏林这张《海浪》全幅。

像的地方，是他们都把水从风景里拎出来，当成唯一的题目，而且都不是只画一张。马远写十二种水；库尔贝对着同一类浪，画了许多幅。

不一样的，是做法。马远在写水的语法：每一段换一套线，泡沫仍是空心的圈。库尔贝是反复做同一道题——浪在翻过来之前的那一瞬，油彩几乎有墙的分量。

[画面] 尺幅对照一次：手卷一段，对墙上的大画。

还有大小。水图是案上展开、一段一段看的；柏林这张比一米还高，会朝你压过来。

[画面] 回到《秋水回波》，再横移到《黄河逆流》。

若水不再是背景，画家研究的究竟是水有多少种写法，还是这一浪在倒下之前长什么样？下次展开这卷，先别跳到最像浪的那一段。从《秋水回波》的底边数那些线，再往右移到《黄河逆流》，看同一只手，是怎么换了一种写法。

## 画面与镜头备忘

本集按长卷拍，不要把十二段当成互不相关的册页。Commons 英译作 Water Album，形制是手卷。横移跟口播句读走：局部 → 半幅 → 全幅 → 再横向卷到下一段，观点后出。
