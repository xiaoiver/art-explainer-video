# 三分钟版｜《墨葡萄图》与梵高的鸢尾（融合稿）

核对日期：2026-11-10。配套 [案例简报](./xuwei-mogu-tao-vangogh-irises-case.md) 与 [来源与权利](./xuwei-mogu-tao-vangogh-irises-SOURCES.md)。

## 口播正文

[画面] 全黑，慢慢起一团浓墨。

先说一个人。八次乡试不中，靠山倒了之后下过狱，出狱时五十多岁。晚年住绍兴，卖画换米。

他叫徐渭。

[画面] 《墨葡萄图》全轴，一人多高。

三百年后的法国南部，另一个人住进精神病院，刚从一场崩溃里出来。院墙里有一小块花园，他每天去画那片鸢尾。

他叫梵高。

两个人中间隔着三百年和一整片大陆。但他们做了同一个决定：在最说不出话的时候，画一株植物，让它替自己开口。

[画面] 葡萄局部，浓墨一颗颗点出。

先看这张画最容易被忽略的一点：它用了三种墨，也就有了三种时间。

葡萄是浓墨，饱满地点出来，不勾轮廓，点与点之间留一口气，光从那里进来。叶子不用线，大块墨铺下去，趁湿破开，浓淡自己渗，那是还活着的潮湿。藤最后画，焦墨、飞白、干笔蹭过去，一路拖出断裂。

果是结出来的，叶是当时活着的，藤是已经死了的。同一张纸上，三段时间并排站着。

[画面] 题诗移入。

画上他自己题了诗。半生落魄，独立书斋，啸晚风。最后两句是：笔底明珠无处卖，闲抛闲掷野藤中。

明珠是他自己。一个卖不掉的人，被他自己画成卖不掉的果子，扔在野藤里。诗不是装饰，是说明书——他把「无处卖」直接钉进画面。

[画面] 《鸢尾花》1889，盖蒂藏。

梵高那张鸢尾，构图往下压。地平线很高，几乎不给天空，花挤在画面下半部。左边一朵白花，孤零零的。每一片叶子的方向都单独定过。

他不在画上写诗。他写给弟弟的信里说的是颜色：紫鸢尾要撞上一块刺眼的柠檬黄，让两边互相把对方点着。一个把「无处卖」写进画里；一个把「颜色怎么烧」写进信里。

这里还有个差别值得记住：水墨不容你回头，藤一笔下去不能再改。梵高的颜料可以改，他一层层加上去，颜色自己堆成体积。所以在梵高那里你能看见时间被加出来，在徐渭那里你只看得见一个瞬间。

[画面] 两幅局部并置。

他们真正像的地方，不是笔法，也不是都画植物。

是他们各自把一株植物推到最前面，把天地、故事、观者全部推出去，只留下这一样东西，让这东西长出人的表情。而两株植物，一个被扔进野藤，一个种在院墙里，都是被弃置的。

两个传统都急着说：他疯了，所以画成这样。这句话对两个人都太省事。徐渭知道草书入画会成什么样，梵高知道黄紫并置会成什么样——表面的激烈底下，是极清醒的控制。

[画面] 徐渭飞白的藤，停住。

下次你站到《墨葡萄图》前面，别先看葡萄。先找那根藤，看它从哪儿起，在哪儿断，断的地方笔毛是怎么散的。

那一笔比他所有的传说都更接近他本人。
