# 案例：顾恺之《洛神赋图》卷（宋摹）× 提香《巴库斯与阿里阿德涅》——神与人在水岸相遇

状态：预制作资料 + 九十秒至两分钟口播稿（2026-11-17）。尚未配音、尚未分镜 JSON、未改 SKILL／styles。

## 选题一句

两边都把关键动作放在水岸上的相遇：一边是人，一边是从另一侧到来的神，中间留出一段看得见的间隔。真正要看的不是「都画了神话」，而是当神出现在岸边，画要留下的是来不及抓住，还是终于被接走：故宫这卷开首是洛神当风而来、曹植一行停在华盖下，后段洛神驾六龙云车离去、回首张望；国家美术馆那张把到达压进同一瞬间，人已经踏空跃出，头上的星预先写出她将被留下。

## 镜头要点

- 开场钉住洛神当风、红日与龙鸿，局部 → 对岸华盖下的曹植一行 → 点明宋摹与开首相逢，再切到女子扬手、人踏空跃出，以及远处的船和头顶的星，观点后出。
- 必须让观众听见这是宋摹，不是顾恺之亲笔。开首相遇一段要让中间的水岸间隔可看见。后段云车必须用已核为同一卷本幅的画面。
- 人身高／尺幅对照只出一次：二十七点一厘米高、五百七十二点八厘米长，对这张画一百七十六点五厘米高、一百九十一厘米宽。出现在介绍提香的那一句。不要让长卷对近于两米见方的形制或尺度成为本组「像」的主轴。
- 像／不像拆成两拍。分岔落在「当神出现在岸边，画要留下的是来不及抓住，还是终于被接走」：是把相遇和离去分成两段，后段云车回首，还是把到达压进同一瞬间，让跃起和头上的星同时在场。
- 「她将被留下」后留 1–2 秒静场，再进结尾的看画动作。
- 结尾是先看洛神当风的衣带，再看华盖下停住的人，然后看后段云车上她回望的方向，再只盯那个离地的脚和头顶的星十秒，问当神出现在岸边，画要留下的是来不及抓住，还是终于被接走。船与星在全幅里已经看得见。
