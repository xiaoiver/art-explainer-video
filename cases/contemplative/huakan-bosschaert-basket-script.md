# 九十秒至两分钟版｜李嵩《花篮图》页与安布罗修斯·博斯哈尔特《花篮静物》

系列意向：Gallery Mate《读画》中西对读。口播与画面不提 Gallery Mate／GM。中西并置是观看方法，不是影响史。

核对日期：2026-11-17。口播正文按这次定稿；制作备忘里的用词修正不改口播，除非成片前另定。

## 口播正文

[画面] 钩子：左下款「李嵩画」，以及编得很细的篮梁。先极近钉住款字和篮梁，再带到满出篮子的花和底下的素绢。不要先报李嵩生平，也不要先报花名名单。

左下写着「李嵩画」。篮子的梁编得很细，花从篮子里满出来，底下是一块没有沿的素绢。

[画面] 全幅本页：篮子停在素绢上，四周没有桌沿，也没有落下的花或虫。左下款与项氏印可看见，但口播只点款，不念藏印。

这是故宫的一页《花篮图》。南宋，李嵩绘，绢本设色。一只花篮就把这一整页占满了。

[画面] 换到博斯哈尔特：还是一只装满折花的浅篮，但已放在石沿上；沿前倒下的花、蜻蜓和蝴蝶，以及左下 .AB.1614. 要能被看见。不要用国家美术馆 NG6549 玻璃瓶那张顶替，也不要串到 Getty 的梵高《鸢尾花》。

换一张。还是一只浅篮，装满折下来的花。可是篮子已经放在石沿上，沿前有花躺着，蜻蜓和蝴蝶也在。左下写着 .AB.1614.

[画面] 《花篮静物》全幅（无框）；尺幅对照只出这一次。石沿、倒下的花和昆虫保持可见。只报画心，不报带框。不要报展厅。

这是安布罗修斯·博斯哈尔特的《花篮静物》，一六一四年。故宫这页十九点一厘米高、二十六点五厘米宽，这张画三十点五厘米高、三十八点九厘米宽。

[画面] 两画并置：两边都是一只编过的浅篮，里面装满折下来的花。

像的地方，是两边都把折下来的花，收进一只编得很认真的浅篮。编织也是要看的东西，不只是盛花的器具。

[画面] 左：李嵩的篮子停在素绢上，没有石沿，没有落下的花，也没有虫；右：篮子放在石沿上，花已经躺到外面，虫停在花上。

不一样的，眼睛就能看见。李嵩的篮子停在素绢上，没有石沿，没有落下的花，也没有虫；那一张把篮子放在石沿上，花已经躺到外面，虫停在花上。

[画面] 回到故宫这页，先看左下那三字「李嵩画」，再看篮梁是怎么编的；然后只盯石沿上倒下的那几枝花十秒，再数一数停在花上的虫。倒下的花和虫在全幅里已经看得见，也有更紧的石沿裁切可用。

下次先看左下那三字「李嵩画」，再看篮梁是怎么编的。然后只盯石沿上倒下的那几枝花十秒，再数一数停在花上的虫。一只篮子被允许做什么——是把某一个时节收成完整的世界，还是把不能同时存在的花强留在同一刻，并让人看见它们已经开始离开？

## 画面与镜头备忘

口播约 430 字（精确 432，不计空白），读下来大概一分半。开场钉在左下「李嵩画」与编得很细的篮梁上，局部 → 满出的花和素绢 → 全幅本页，再切到石沿上的篮子、倒下的花、蜻蜓与蝴蝶，以及左下 .AB.1614.，观点后出。必须锁在故宫这一页《花篮图》（文物号新00146350，南宋，李嵩绘）和盖蒂博物馆安布罗修斯·博斯哈尔特《Flower Still Life》（83.PC.386）上，不要用台北故宫、龙美术馆或其他带「李嵩」款的花篮页来顶替，也不要用国家美术馆同一年的《Flowers in a Glass Vase》（NG6549，玻璃瓶而非篮子）来顶替，更不要串到 Getty 已用于徐渭一组的梵高《鸢尾花》。开口可见左下「李嵩画」，作者只说「南宋，李嵩绘」，与当前藏品页一致，不要口说「传李嵩」。西画年代只说「一六一四年」。不要把其中一页的花名说成唯一鉴定名单，也不要把「四季之一 / 夏」说成藏品页已写的事实。
