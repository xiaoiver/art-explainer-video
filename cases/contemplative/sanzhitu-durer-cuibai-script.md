# 约一百一十秒版｜三只兔（丢勒《野兔》× 崔白《双喜图》× 敦煌三兔共耳）

系列意向：Gallery Mate《读画》中西对读。口播与画面不提 Gallery Mate／GM。中西并置是观看方法，不是影响史。本集是三项并读，不是双边配对。

核对日期：2026-11-11。口播正文按这次定稿；制作备忘里的用词修正不改口播，除非成片前另定。

## 口播正文

[画面] 一只野兔，画在纸上，四周全空。

第一只兔，1502 年，丢勒画的。它四周什么都没有，没有草、没有地面、没有影子。你放大看，每根毛的方向都不一样，眼里还有一点白。他用的是最细的笔，一根一根描出来的。

这只兔，不被任何东西惊动。

[画面] 《双喜图》全幅，坡上的兔，枝头的两只喜鹊。

换一张。1061 年，崔白画的。兔在坡上，两只山喜鹊在枝头冲它叫。它回过头，耳朵立着，一只前爪悬在半空。

这只兔被惊动了。

宋人画这种东西不叫写生，叫生意。意思是，你不只要把它画全，还要让它在画里活着。所以兔旁边一定有鹊，有风，有枝子在动。它为什么回头，画里有答案。

[画面] 两张兔脸局部并置。

所以中国画里没有丢勒那种兔，不是画不出来。易元吉为了画猿猴，在院子里养猿；宋人画草虫能细到翅脉。技术上没问题。

差别在目的上。丢勒要的是一个个体的完整记录，像一份档案。崔白要的是动物和世界之间那根绷着的线，是那一刻。

一只被惊动的兔，和一只不被惊动的兔。

[画面] 三兔共耳，敦煌藻井，一圈跑不出去的兔。

还有第三只。

它其实不算一只，是三只。三只兔绕成一个圈，共用三只耳朵，一只接一只地跑，永远追不上，也永远停不下来。

这个图案在莫高窟隋代的藻井里有，中亚的陶器上有，伊朗的铜盘上有，十三世纪以后，出现在英国教堂的屋顶上。

谁传给谁，到现在还没有定论。

它一点都不像真的兔。但它走了最远的路。

[画面] 三张图依次缩小，黑场。

一只停在纸上的兔，一只回头的兔，一圈跑不完的兔。

下次你在展厅里看到一只兔，先问一句：它是被什么惊动的。

## 画面与镜头备忘

口播约 540 字，按 110 秒会偏赶，读慢一点大概两分钟。若卡死 110 秒，削一两处列举，不要改论点。画面从空纸上的兔切入；口播仍以年代和画家起句，成片前若要改成更物件优先的开场，另定，不要在制作里擅自改正文。

| 口播锚点 | 建议画面 | 镜头 |
| --- | --- | --- |
| 一只野兔，画在纸上，四周全空 | 丢勒《野兔》全幅，先看见四周的空纸 | 物件开场：先让空纸和这只兔自己说话。不要先报画家生平。轻推或短暂停在毛与眼睛，不要箭头轰炸。 |
| 没有草、没有地面、没有影子；每根毛；眼里一点白 | 仍是这张纸本；可慢推到眼与须 | 馆方写明影子落向右侧，预览里也看得到；「没有草、没有地面」成立。眼里那一点白，馆方说是画室窗户的倒影。「没有影子」先按定稿，不要在画面上把影子裁掉或涂掉来迁就口播。 |
| 这只兔，不被任何东西惊动 | 回到几乎全幅，四周仍留空 | 停半拍。不要用旧的「受惊野兔」读法覆盖馆方「安然坐在空地里」的说明。 |
| 换一张。《双喜图》全幅 | 立轴全幅：坡上的兔，枝上与腾空的鹊 | 按立轴竖推，不要拍成横构图的局部拼贴。若做一次尺幅对照，只放在「换一张」之后：巴掌大的纸本，对近两米的立轴。人身高对照最多出一次。 |
| 它回过头，耳朵立着，一只前爪悬在半空 | 兔的局部，能看见回头、抬起的右前爪 | 右前爪悬起是清楚的。两只耳朵实际贴在颈后，并不竖起；口播「耳朵立着」先按定稿。两只山喜鹊是一只展翅腾空、一只在枝头鼓噪，不是两只都停在枝头。 |

| 两张兔脸局部并置 | 左：丢勒眼与吻；右：崔白回头的脸 | 像／不像拆成两拍：先技术上画得出来，再落到目的。一个镜头只塞一个新信息。 |

| 还有第三只……三兔共耳 | 莫高窟隋代藻井，优先第 407 窟三兔莲花井心；看清共用的三只耳朵和跑动的圈 | 不要编造传播路径。敦煌研究院照片可能受影像权限制，仓库不收母版；成片用图需另走授权，不要用权属不明的网图顶上。 |

| 谁传给谁，到现在还没有定论 | 回到敦煌藻井，或三处并置极短一拍 | 不要用箭头连成一条传布路线。独立发生的说法也存在，口播已经停在「无定论」。 |
| 一只停在纸上的兔……它是被什么惊动的 | 三张图依次缩小，黑场 | 片尾只留这个可执行的看画动作，不总结生平，不报展览。 |

本集不以画家小像开场。丢勒自画像属公有领域，可备切；崔白无可靠同时代肖像，不要用后出想象像冒充。
