# 案例：李嵩《骷髅幻戏图》× 霍尔拜因《大使们》——摆出来演，还是走过去才看见

状态：预制作资料 + 九十秒至两分钟口播稿（2026-11-12）。尚未配音、尚未分镜 JSON、未改 SKILL／styles。

## 选题一句

两边都把一具骨头放进活人的场面里；真正要看的不是「都有骷髅」，而是一个摆在舞台中央、演给画里的人看，一个藏在脚边，要你侧过身才看见。

## 镜头要点

- 开场钉住大骷髅右手的线，局部 → 半幅 → 全幅，观点后出。
- 团扇保持圆形画心；霍尔拜因按近方形大画来拍，不要裁掉幕布、地板或桌上的物件来制造「只剩头骨」。
- 人身高／尺幅对照只出一次：握在手里的团扇，对刚过两米、与真人差不多高的油画。出现在介绍《大使们》的那一句。
- 先让斜影自己出现，再侧过身揭成头骨；像／不像拆成两拍，分岔落在「位置」。
- 「一个是摆出来演，一个是走过去才看见」后留 1–2 秒静场。
- 这张团扇究竟是市井傀儡戏的记录，还是生死寓言，文献里没有定论；眼睛能核对的，先止步于「它在演戏」。
