# 案例：马远《水图》× 库尔贝《海浪》——水的语法，还是这一浪

状态：预制作资料 + 九十秒至两分钟口播稿（2026-11-10）。尚未配音、尚未分镜 JSON、未改 SKILL／styles。

## 选题一句

两边都把水从风景里拎出来，当成唯一的题目来反复画；真正要看的不是「都在画浪」，而是马远在写水的语法，库尔贝在抓住浪倒下前的那一瞬。

## 镜头要点

- 按手卷横向卷移，不要拍成互不相关的册页。
- 开场钉住《秋水回波》底边的线，局部 → 半幅 → 全幅，再横移；观点后出。
- 人身高／尺幅对照只出一次：杂志大小的一段，对超过一米高的油画。
- 《黄河逆流》浪头接到库尔贝刀刮的白；像／不像拆成两拍。
- 「油彩几乎有墙的分量」后留 1–2 秒静场。
- 不要裁掉柏林画里的地平线、天空和滩石，来制造「只剩水」。
