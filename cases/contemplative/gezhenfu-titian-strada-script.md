# 九十秒至两分钟版｜曾鲸《葛震甫像》与提香《雅各布·斯特拉达》

系列意向：Gallery Mate《读画》中西对读。口播与画面不提 Gallery Mate／GM。中西并置是观看方法，不是影响史。

核对日期：2026-11-13。口播正文按这次定稿；制作备忘里的用词修正不改口播，除非成片前另定。

## 口播正文

[画面] 钩子：葛一龙身子斜倚，腰下垫着一叠书函，袍角露出一点红鞋子，先极近。不要先出全卷，也不要先报曾鲸生平。

他身子斜着，垫在腰下的，是一叠书。袍角还露出一点红鞋子。

[画面] 拉到半幅：人只占一小块，旁边大片空白，写满了同时人的题赞。

人只占这一小块，旁边大片空白，写满了字。这张像，是把人画完了，还是把字也算进去了？

[画面] 全卷调查条带：中间倚书而坐的人，左右都是题赞。不要把这卷裁成只剩人像，也不要把题赞裁掉。手卷按可见顺序看完左右题识。

这是故宫的一卷《葛震甫像》。曾鲸绘，纸本设色。像主葛一龙，字震甫。大致画在崇祯年间。他倚着书函坐下，别无它景，左右都是同时人写下的题赞。

[画面] 换到提香：左手托着的小小女像，右手伸向桌上的钱币，旁边一封折起的信，毛皮从肩上滑下。先钉这些物件，不要先读右上圆牌铭文。

换一张。手里托着一尊小小的女像。另一只手伸向桌上的钱币，旁边还有一封折起的信。毛皮从肩上滑下来。

[画面] 《雅各布·斯特拉达》全幅；尺幅对照只出这一次。

这是提香的《雅各布·斯特拉达》，约一五六七至一五六八年。故宫这卷高三十二点五厘米、长七十七点五厘米，这张画一百二十六厘米高、九十五点五厘米宽。

[画面] 两画并置：一边是书函，一边是古物、钱币和信。

像的地方，是两边都给一个叫得出名字的人写照。他是谁，靠身边留下的东西被看见：一边是书函，一边是古物、钱币和信。

[画面] 左：手卷里人只占四分之一，空白留给朋友来写完；右：大画把房间和物件一起装进画框。

不一样的，眼睛就能看见。一边是手卷，人只占四分之一，空白留给朋友来写完；一边是一张大画，把房间和物件一起装进画框。

[画面] 回到故宫这卷，从那叠书看他怎么倚着坐，再把左右题赞读一遍；然后只盯那尊小雕像十秒，再看桌上的钱币和信。

下次从那叠书数起：先看他怎么倚着书坐，再把左右题赞读一遍。然后只盯那尊小雕像十秒，再看桌上的钱币和信。脸画完了，这张像算写完了吗？

## 画面与镜头备忘

口播约 430 字（精确 433，不计空白），读下来大概一分半。开场钉在斜倚的身子、腰下的书函和袍角那一点红鞋子上，局部 → 半幅（人小、空白与题赞）→ 全卷，再切到小雕像、钱币和信，观点后出。必须锁在故宫这一卷《葛震甫像》（文物号新00147409）和维也纳艺术史博物馆提香《Jacopo Strada》（Gemäldegalerie 81）上，不要用天津《王时敏像》、浙博《张卿子像》，或提香其他男子像来顶替。作者只说「曾鲸绘」，年代只说「大致画在崇祯年间」，不要口说精确到年，也不要把右上圆牌铭文读出来。
