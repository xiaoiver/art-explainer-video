# 九十秒至两分钟版｜顾闳中《韩熙载夜宴图》与伦勃朗《夜巡》

系列意向：Gallery Mate《读画》中西对读。口播与画面不提 Gallery Mate／GM。中西并置是观看方法，不是影响史。

核对日期：2026-11-12。口播正文按这次定稿；制作备忘里的用词修正不改口播，除非成片前另定。

## 口播正文

[画面] 第一段床榻上，那顶高帽，先极近。

这顶高帽，先记住它。

[画面] 拉到半幅：戴高帽的人坐在床上，左侧有人弹琵琶。

戴这顶帽子的人，坐在床上听琵琶。

[画面] 过了屏风：同一个高帽，站在鼓边。

过了这道屏风，这顶帽子怎么又在这儿？还是那把长须，人已经站起来了，站在一面鼓旁边。

[画面] 整卷从右往左横移，经过五段。

这是故宫的一卷《韩熙载夜宴图》。绢本手卷，馆方定为南宋摹本。屏风把一个晚上隔成五段。同一个人，出现了五次。你得从右往左卷过去，才看完这一夜。

[画面] 《夜巡》人群，先半幅。

换一张。这么多人，站在同一面墙上。

[画面] 全幅《夜巡》。

这是 1642 年，伦勃朗给阿姆斯特丹市民卫队大厅画的《夜巡》。这张画将近四米高。站在它前面，画里的人差不多和你一样高。每个人只出现一次。

[画面] 两张并置。

像的地方，是两边都把一次聚会，当成必须交代清楚的场面。谁在场，在做什么。画不是气氛装饰，是一份要被看完的记录。

不一样的，是这份报告怎么摊开。夜宴图把时间摊开：同一个人出现五次，从右往左才看完一夜。《夜巡》把一队人摊在同一刻：每个人只出现一次。

一个是一个晚上里同一个人的几次露面，一个是同一时刻里的许多人。

[画面] 回到夜宴图，从右往左再卷，再看《夜巡》。

下次看这两张，把夜宴图再卷一遍，数他出现了几次。再看《夜巡》，每个人是不是只出现一次。

## 画面与镜头备忘

口播约 420 字，读下来大概一分半。若卡死 90 秒，可略收「还是那把长须，人已经站起来了，站在一面鼓旁边」，或「画不是气氛装饰，是一份要被看完的记录」，不要改论点。开场钉在高帽上，局部 → 半幅 → 过屏风，再整卷横移，观点后出。按手卷从右往左拍，不要拍成五张互不相关的册页。

| 口播锚点 | 建议画面 | 镜头 |
| --- | --- | --- |
| 这顶高帽，先记住它。 | 第一段床榻上那顶高帽，先极近 | 物件开场：先钉住可见的局部，不要先报顾闳中生平，也不要先讲李煜派画师去偷窥。轻推，不要箭头轰炸。 |
| 戴这顶帽子的人，坐在床上听琵琶。 | 拉到半幅：高帽、长须、坐在床上，左侧弹琵琶的女子 | 琵琶是清楚的。一个镜头只塞一个新信息。宾客姓名来自著录传统，本幅无款，不要当成画上题名来读。 |
| 过了这道屏风，这顶帽子怎么又在这儿？……站在一面鼓旁边 | 同一道屏风的两边：右边仍是听琵琶的那顶高帽，左边他已站在鼓边 | 这是发现的一拍。让眼睛自己对上两顶帽子。横移从右往左，不要跳切。口播用「一面鼓」即可，不必读成「羯鼓」。 |
| 这是故宫的一卷……才看完这一夜 | 整卷从右往左横移，经过五段 | 「南宋摹本」要说，不要把这卷说成顾闳中原作。暂歇一段里，他坐在床沿洗手，头上的帽子明显比其余四段那顶高帽矮；口播说的是「同一个人出现了五次」，不要改成「高帽出现五次」。卷上后出的题跋和印鉴可入画，口播不读。 |
| 换一张。这么多人，站在同一面墙上 | 《夜巡》半幅，先看见人群 | 先让人群自己出现，不要先讲官司、裁切史，或「其实不是夜景」。 |
| 这是 1642 年……每个人只出现一次 | 全幅《夜巡》 | 尺幅对照只出这一次：将近四米高，与画中人差不多高。不要说「两人高」（那会变成三米以上）。后墙上那块写着名字的盾可入画，不要读出来，也不要说是伦勃朗当场写上的。 |
| 像的地方……要被看完的记录 | 两画并置，先全幅 | 像／不像拆成两拍。一个镜头只塞一个新信息。 |
| 不一样的……每个人只出现一次 | 左：手卷里同一人的几次露面；右：墙上每人只出现一次的群像 | 「怎么摊开」是本集的分岔。不要把夜宴图裁成只剩一张面孔，也不要把《夜巡》裁成只剩两名主将。 |
| 一个是一个晚上里同一个人的几次露面，一个是同一时刻里的许多人 | 并置再稍稍拉开 | 这是论点收束处，建议此处静 1–2 秒，口播闭嘴。 |
| 下次看这两张……只出现一次 | 回到夜宴图，从右往左再卷，数人；再看《夜巡》 | 片尾只留这个可执行的看画动作。是数人，不是数高帽（暂歇那段帽子较矮）。不要让观众去对《夜巡》的名单盾。不总结生平，不报展览。 |

本集不以画家小像开场。伦勃朗自画像属公有领域，可备切；顾闳中无可靠同时代肖像，不要用后出想象像冒充。五段目验：听乐坐床听琵琶（高帽）、观舞立于鼓边（高帽）、暂歇坐床洗手（矮帽）、清吹白衣坐着（高帽）、散宴站着（高帽）。
