# 九十秒至两分钟版｜李嵩《骷髅幻戏图》与霍尔拜因《大使们》

系列意向：Gallery Mate《读画》中西对读。口播与画面不提 Gallery Mate／GM。中西并置是观看方法，不是影响史。

核对日期：2026-11-12。口播正文按这次定稿；制作备忘里的用词修正不改口播，除非成片前另定。

## 口播正文

[画面] 大骷髅的右手，那几根线。

这只手在提线。提的是什么？

[画面] 拉到小骷髅，再半幅：大骷髅、小骷髅、爬过来的孩子。

是一具小骷髅。大骷髅坐在那儿，戴着幞头，穿着纱衣，右手提着线。对面一个孩子正爬过去，伸着手。

[画面] 全幅团扇：哺乳的妇人，行囊，空地。

后面的妇人在喂奶，神情安然。这是南宋李嵩的一张团扇，《骷髅幻戏图》，可以握在手里。大骷髅在演戏，画里的人在看。

[画面] 《大使们》脚边那条斜影，先极近。

换一张。两人脚边，横着一条拉长的影子。

[画面] 拉到半幅，再全幅：两个大使、绿色幕布、桌上物件。

这是 1533 年，霍尔拜因在伦敦画的《大使们》。这张画刚过两米，站在它前面，你和画里的人差不多高。两个大使站在绿色的幕布前，中间是地球仪、琴和书。他们并不看脚边那条影子。

[画面] 侧过身／透视校正后的头骨。

你走到画面右下角，侧过身。那条影子变成了一具头骨。

[画面] 两张并置。

像的地方，是两边都把一具骨头，放进了活人的场面里。死亡不是写在边上的一句话，是你必须用眼睛去找的东西。

不一样的，是位置。李嵩把骷髅摆在舞台中央，它是主角，画里的人正在看这场戏。霍尔拜因把头骨藏起来，死亡是给画外的人准备的。

一个是摆出来演，一个是走过去才看见。

[画面] 回到李嵩的线，再把《大使们》斜过来。

下次看这两张，先看清李嵩画里那些线，和小骷髅怎么站。再把《大使们》斜过来，看两人脚边那条影子，何时变成头骨。

## 画面与镜头备忘

口播约 430 字，读下来大概一分半。若卡死 90 秒，可略收「地球仪、琴和书」一句，不要改论点。开场钉在提线上，局部 → 半幅 → 全幅，观点后出。团扇保持圆形画心，不要裁成方画来迁就并置。

| 口播锚点 | 建议画面 | 镜头 |

| 这只手在提线。提的是什么？ | 大骷髅右手与那几根丝线，先极近 | 物件开场：先钉住可见的局部再发问，不要先报画家生平。轻推，不要箭头轰炸。 |
| 是一具小骷髅……伸着手 | 拉出小骷髅，再半幅：提线的手、小骷髅、爬过来的孩子 | 小骷髅右脚着地、左脚抬起，线是清楚的。一个镜头只塞一个新信息。 |
| 后面的妇人在喂奶……画里的人在看 | 全幅团扇，圆轮廓还在；能看见哺乳的妇人、行囊、「李嵩」款 | 「可以握在手里」让画心自己说话。墩子上的「五里」入画即可，口播不读，也不要解释成坟墓或生死关口。 |
| 换一张。两人脚边，横着一条拉长的影子 | 《大使们》底部斜影，先极近 | 先让这条影子自己出现，还不要揭成头骨。不要先讲亨利八世或宗教改革。 |
| 这张画刚过两米……他们并不看脚边那条影子 | 拉到半幅，再全幅：两个站着的人、绿色幕布、架子上的地球仪、琴和书 | 尺幅对照只出这一次：握在手里的团扇，对刚过两米、与真人差不多高的油画。两个大使看着画外，确实没有在看地板上的斜影。「绿色的幕布」不要写成「绿幕」。 |
| 你走到画面右下角，侧过身。那条影子变成了一具头骨 | 按馆方说的右下角视角，或用透视校正后的头骨图辅助说明 | 这是发现的一拍。仓库里的校正图是把斜影按透视拉正的结果，不是在展厅里拍到的侧视照片；成片要用它，先说明这是同一条斜影被看正之后的样子。 |

| 不一样的，是位置……给画外的人准备的 | 左：舞台中央的大骷髅；右：脚边被藏起来的斜影 | 「位置」是本集的分岔，不要把霍尔拜因这张只收成一颗头骨——桌上的物件还在。 |
| 一个是摆出来演，一个是走过去才看见 | 并置再稍稍拉开 | 这是论点收束处，建议此处静 1–2 秒，口播闭嘴。 |
| 下次看这两张……何时变成头骨 | 回到李嵩的线，再把《大使们》斜过来，句号处停 | 片尾只留这个可执行的看画动作，不总结生平，不报展览，不把画题解释成已有定论的寓言。 |

本集不以画家小像开场。霍尔拜因的自画像属公有领域，可备切；李嵩无可靠同时代肖像，不要用后出想象像冒充。左上角幕布后的十字架是馆方指出的另一处隐藏，口播不提，不要在成片里抢「侧过身看头骨」这一拍。
