# 九十秒版｜牧溪《六柿图》与莫兰迪的瓶罐

系列意向：Gallery Mate《读画》中西对读。口播与画面不提 Gallery Mate／GM。中西并置是观看方法，不是影响史。

核对日期：2026-11-10。口播正文按用户定稿；制作备忘里的用词修正不改口播，除非成片前另定。

## 口播正文

[画面] 六个墨点，小册页。

有两张画，第一眼几乎没什么可看。一张上只有六个柿子，另一张上只有几个瓶子。

[画面] 《六柿图》，大德寺龙光院。

六个柿子横排，什么背景都没有。没有桌子，没有影子，底下空着。墨色从浓到淡分了好几层，中间那只最黑。

画他的人叫牧溪，南宋的禅僧。元代的评论家说这种画算不上清玩，只配挂在僧房里。这张画后来传到日本，进了大德寺龙光院，现在是人家的国宝。

[画面] 莫兰迪的瓶罐。

另一边是博洛尼亚，二十世纪。一个人一辈子没离开那座城，桌上永远摆着同一批瓶子，据说还让它们积着灰，好让边缘不那么利。他一幅画能画很久，反复覆盖、擦掉、重来，直到所有东西都退进同一种灰。

[画面] 并置。

像的地方是：都把东西压到最少，都不讲故事。少不是空，是把你没有别的东西可看，只能看这几个。

不一样的是灰的来路。牧溪的灰是墨和水在纸上争出来的，一笔下去不能改，那是他手上那一瞬的判断。莫兰迪的灰是磨出来的，改位置、改光，一遍遍覆盖，那是时间在东西上留下的磨损。

[画面] 拉远。

下次站到这张画前面，从左边数到右边，看墨色怎么走。六个果子，没有别的，它要求你做的事，比看一幅大画难得多。

## 画面与镜头备忘

本集适合用上的默认镜头语法：人身高对照一次、局部／全局标注、横排慢移。它不是手卷，不要做成长卷横向滚屏；「从左边数到右边」是六个柿子的横排阅读。

| 口播锚点 | 建议画面 | 镜头 |
| --- | --- | --- |
| 六个墨点，小册页 | 《六柿图》画心，先极近再略拉开 | 物件开场：先钉住两三颗墨点，再问「这是什么」。人身高／尺幅对照只出一次——画心约一本杂志大小（约 35×29 cm），往人胸口或手掌比一下就够，不要反复刷。口播「小册页」说的是尺幅小；现装是挂轴，不是册页。 |
| 几乎没什么可看 | 六柿全幅，停半拍 | 观点还没出来，先让画面自己说话。 |
| 六个柿子横排……底下空着 | 全幅，轻描边或淡字标「没有桌子／没有影子」 | 标注用轻描边或慢推，不要箭头轰炸。 |
| 墨色分了好几层，中间那只最黑 | 从左到右慢移，在最黑那只上停 | 制作时按左起数：最黑的通常是第四只，不是正中间；口播「中间」是观感。全局回切时停半拍，让观众对位。 |
| 牧溪……只配挂在僧房里 | 全幅或茶席床の间语境图（若有许可） | 不要用画家画像硬填，除非另核可靠小像。出处见 [SOURCES](./muxi-liushi-morandi-SOURCES.md)：这句话是庄肃《画继补遗》，不是汤垕。 |
| 传到日本……国宝 | 龙光院／大德寺外景或名款卡 | 正式等级是日本「重要文化财」（1919 年指定），不是「国宝」。口播若要改严谨，可换成「现在是日本的重要文化财」。 |
| 莫兰迪的瓶罐 | 馆方面页允许的静物（见 [SOURCES](./muxi-liushi-morandi-SOURCES.md) 候选），仓库不入库原图 | 先近景瓶口／积灰边缘，再拉开到整组。版权仍在保护期内，成片用馆方授权或清晰标注的引用，不从仓库调图。 |
| 一辈子没离开那座城……积着灰 | 工作室／Via Fondazza 历史照片（若有许可）或静物局部 | 「没离开那座城」是修辞压缩：他常年住博洛尼亚，夏天在 Grizzana，晚年还去过瑞士和巴黎。积灰软化的是反光和表面，[SOURCES](./muxi-liushi-morandi-SOURCES.md) 里有 Rewald／Tate 出处；「边缘不那么利」是观看概括，不要写成莫兰迪原话。 |
| 像的地方……只能看这几个 | 两画并置，先全幅后局部 | 一个镜头只塞一个新信息；先并置「少」，再切到「灰的来路」。 |
| 灰的来路 | 左：柿子水墨渗透；右：瓶罐涂层重叠 | 像在哪里／不像在哪里拆成两拍。高潮这句后故意静 1–2 秒，口播闭嘴。 |
| 从左边数到右边 | 回到六柿，左→右横移，句号处停 | 节奏跟口播句读走。片尾只留这个可执行的看画动作，不总结生平。 |

若卡死 90 秒，可删「据说还让它们积着灰，好让边缘不那么利」一句，积灰改放到画面标注。
