# 案例：传宋徽宗《捣练图》× 委拉斯开兹《纺纱女》——哪一张画里，劳动本身就是故事

状态：预制作资料 + 九十秒至两分钟口播稿（2026-11-13）。尚未配音、尚未分镜 JSON、未改 SKILL／styles。

## 选题一句

两边都让你跟着女人的手，把纺织的活一步步看完。真正要看的不是「都在画女工」，而是故事放在工序的哪一层：波士顿这卷手卷把捣、缝、熨依次铺开，劳动的顺序就是叙事；普拉多那张大画把作坊顶在眼前，神话却嵌在后面一块亮处。

## 镜头要点

- 开场钉住绷平的白练和从下面钻过的小孩，局部 → 熨练一组 → 画心自右向左横移，再切到纺车、前景作坊、后景亮处，观点后出。
- 必须让观众看见捣、缝、熨是顺着手卷一站接一站排开的，不要把带题跋的全卷装裱当成主调查图。
- 人身高／尺幅对照只出一次：画心三十七厘米高、一百四十五厘米长，对这张画两百二十厘米高、两百八十九厘米宽。出现在介绍《纺纱女》的那一句。不要说「两人高」，不要让尺度成为本组「像」的主轴。
- 像／不像拆成两拍。分岔落在「故事是顺着工序走，还是藏在工序后面」。
- 「故事却嵌在后面那块亮处」后留 1–2 秒静场，再进结尾的看画动作。
- 结尾是从右往左走完这卷，在小孩钻过白练的地方停住，再盯纺车十秒，然后走进后面的壁毯，问哪一张里劳动本身就是故事，哪一张里劳动只是故事的前厅。
